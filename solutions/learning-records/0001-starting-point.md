# 起点：从 ReLU 开始系统学习 PyTorch 手撕题

用户目标是通过 TorchCode 的 41 道题系统提升 PyTorch 核心算子手撕能力，目标场景是顶级 ML 团队白板面试。学习从最基础的 ReLU 开始，按顺序逐题推进。

**Evidence**: 用户主动要求"one by one 手撕各个文档"，明确表示"目前都得学一遍"，说明起点是全覆盖式系统学习，而非针对薄弱点补课。

**Implications**: 初期题目（ReLU、Softmax、Linear 等）可能较简单，但应彻底讲解 PyTorch 惯用法（布尔掩码、einsum、autograd 机制），这些技巧会在后续复杂题目中反复用到。不要因为题目简单就跳过基础概念。
