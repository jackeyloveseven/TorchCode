第 12 课Hard

线性注意力

核技巧消灭 softmax，结合律改变计算顺序，复杂度从 O(S²D) 降到 O(SD²)。

学习目标

  • 理解用核特征映射替换 softmax 的思想
  • 掌握结合律技巧：先算 KTV，避免 S×S 矩阵
  • 理解 elu + 1 特征映射保证非负的原因

核心概念

标准注意力：softmax(QKT/√d) · V，需要 O(S²) 空间存中间矩阵。

线性注意力用核特征映射 φ 替换 softmax：

LinearAttn(Q,K,V) = φ(Q) · (φ(K)TV) / (φ(Q) · Σφ(K))

关键：矩阵乘法结合律

# 标准：先算 S×S 注意力矩阵（S可能很大）
out = softmax(Q @ K.T) @ V            # O(S²D) 时间，O(S²) 空间

# 线性：先算 D×D 的 K^T V
KV  = K_prime.transpose(1,2) @ V     # (B, D_k, D_v)，O(SD²)
out = Q_prime @ KV                   # (B, S, D_v)，O(SD²)
# 总体 O(SD²) 时间，O(D²) 空间！

为什么用 φ(x) = elu(x) + 1？

核技巧要求特征映射非负（保证"注意力权重"非负）。elu(x) + 1： x>0 时 = x+1 > 0，x<0 时 = exp(x) > 0，始终正。

PyTorch 实现

def linear_attention(Q, K, V):
    # φ(x) = elu(x) + 1
    Q_prime = F.elu(Q) + 1   # (B, S, D_k)
    K_prime = F.elu(K) + 1

    KV  = torch.bmm(K_prime.transpose(1, 2), V)      # (B, D_k, D_v)
    Z   = K_prime.sum(dim=1, keepdim=True)            # (B, 1, D_k)，归一化分母

    num = torch.bmm(Q_prime, KV)                      # (B, S, D_v)
    den = torch.bmm(Q_prime, Z.transpose(1, 2))       # (B, S, 1)
    return num / (den + 1e-6)
Z 的含义：Z = Σ_j φ(K_j)，相当于所有 K 特征之和， 是分母（归一化项），确保输出是加权平均而不是加权和。

测验

Q1 · 复杂度优化

线性注意力如何避免 O(S²) 复杂度？

  • A 稀疏化 Q/K/V
  • B 量化 Q/K/V 为低精度
  • C 改变矩阵乘法顺序：先 KTV（D×D），再 Q*(KTV）
  • D 用滑动窗口限制关注范围

Q2 · 特征映射

为什么选 φ(x) = elu(x) + 1 而不是直接用 relu(x)？

  • A relu 计算更慢
  • B relu 在 x<0 时为 0，导致分母为 0；elu+1 始终严格正
  • C elu 更接近 softmax 的行为
  • D relu 不支持梯度

Q3 · Z 的作用

代码中 Z = K_prime.sum(dim=1) 的作用是？

  • A 归一化分母，对应 softmax 的行和为 1
  • B 计算 K 的均值
  • C 数值稳定性，类似 max 减法
  • D 没有实际意义，只是 placeholder

参考解法

def linear_attention(Q, K, V):
    Q_prime = F.elu(Q) + 1
    K_prime = F.elu(K) + 1
    KV  = torch.bmm(K_prime.transpose(1, 2), V)   # (B, D_k, D_v)
    Z   = K_prime.sum(dim=1, keepdim=True)          # (B, 1, D_k)
    num = torch.bmm(Q_prime, KV)                   # (B, S, D_v)
    den = torch.bmm(Q_prime, Z.transpose(1, 2))    # (B, S, 1)
    return num / (den + 1e-6)

面试要点

  • 核心思路：结合律改变计算顺序，先算 KTV
  • 特征映射：φ(x) = elu(x) + 1，保证非负
  • 复杂度：O(SD²) 时间，O(D²) 额外空间，摆脱 S² 依赖
  • 代价：近似 softmax，质量略低；适合超长序列
