第 06 课Hard

多头注意力

h 个注意力头并行，关键是 reshape 成 (B, h, S, d_k)。

学习目标

  • 理解多头注意力如何让模型从不同子空间关注不同位置
  • 掌握 view + transpose 实现多头分割的技巧
  • 理解最终 concat + W_o 投影的作用

核心概念

MultiHead(Q,K,V) = Concat(head₁,…,head_h) · WO

其中每个头 head_i = Attention(Q·W_i^Q, K·W_i^K, V·W_i^V)

为什么多头？单头注意力只能在一个表示子空间中关注。多头让模型同时 关注不同位置的不同语义信息（句法、语义、共指…），最后拼接融合。

关键 reshape 流程

# 输入 x: (B, S, D)，D = h * d_k
Q = W_q(x)                           # (B, S, D)
Q = Q.view(B, S, h, d_k)             # 分成 h 个头
Q = Q.transpose(1, 2)                # (B, h, S, d_k)
# 对每个头独立做注意力，结果: (B, h, S, d_k)
# 再 transpose + reshape 拼回 (B, S, D)
out = out.transpose(1, 2).contiguous().view(B, S, D)

PyTorch 实现

import math, torch
import torch.nn as nn

class MultiHeadAttention:
    def __init__(self, d_model, num_heads):
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, Q, K, V):
        B, S, D = Q.shape
        h, dk = self.num_heads, self.d_k

        # 投影 + 分头
        q = self.W_q(Q).view(B, S, h, dk).transpose(1, 2)   # (B, h, S, dk)
        k = self.W_k(K).view(B, -1, h, dk).transpose(1, 2)
        v = self.W_v(V).view(B, -1, h, dk).transpose(1, 2)

        # 注意力
        scores  = (q @ k.transpose(-2, -1)) / math.sqrt(dk)  # (B, h, S, S)
        weights = torch.softmax(scores, dim=-1)
        out = weights @ v                                      # (B, h, S, dk)

        # 合并头
        out = out.transpose(1, 2).contiguous().view(B, S, D)  # (B, S, D)
        return self.W_o(out)
contiguous()：transpose 不移动内存，只改 stride，导致张量非连续。 .view() 要求连续内存，所以要先 .contiguous()， 或者改用 .reshape()（内部会自动处理）。

测验

Q1 · 头维度

d_model=512, num_heads=8 时，每个头的维度 d_k 是？

  • A 512
  • B 64
  • C 128
  • D 4096

Q2 · reshape 流程

Q.view(B, S, h, dk).transpose(1, 2) 的结果 shape？

  • A (B, S, h, dk)
  • B (B, dk, S, h)
  • C (B, h, S, dk)
  • D (h, B, S, dk)

Q3 · contiguous

合并头时为什么需要 .contiguous()？

  • A transpose 返回非连续张量，view() 要求连续内存
  • B 让梯度能正常反向传播
  • C 提升计算速度
  • D 合并多个张量时的必要步骤

面试要点

  • 分头：view(B,S,h,dk).transpose(1,2) → (B,h,S,dk)
  • 合并：transpose(1,2).contiguous().view(B,S,D)
  • contiguous：transpose 后必须调用，或改用 reshape
  • 延伸：GQA（num_kv_heads < num_heads），KV 头被多组 Q 头共享
