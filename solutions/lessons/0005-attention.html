Scaled Dot-Product Attention

Transformer 的核心——三行代码，一辈子用不完。

学习目标

  • 理解 Q/K/V 的含义与 Attention = softmax(QKT/√d_k)V 的推导
  • 掌握 torch.bmm 做批量矩阵乘
  • 理解为什么要除以 √d_k（缩放的作用）

核心概念

Attention(Q, K, V) = softmax(QKT / √d_k) · V

Q（Query）：当前 token 想查什么
K（Key）：每个 token 提供的索引
V（Value）：每个 token 实际的内容

点积 QKT 衡量 Query 和每个 Key 的相似度，softmax 把相似度变成权重，再加权求 V。

为什么除以 √d_k？

若 Q 和 K 的元素服从标准正态，QKT 的单元素方差 ≈ d_k。 当 d_k 大时，点积绝对值很大，落入 softmax 的饱和区（梯度接近 0）。 除以 √d_k 让方差回到 1，梯度更健康。

PyTorch 实现

import math, torch

def scaled_dot_product_attention(Q, K, V):
    # Q: (B, S_q, d_k), K: (B, S_k, d_k), V: (B, S_k, d_v)
    d_k = K.size(-1)
    scores  = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(d_k)  # (B, S_q, S_k)
    weights = torch.softmax(scores, dim=-1)                       # (B, S_q, S_k)
    return torch.bmm(weights, V)                                  # (B, S_q, d_v)

torch.bmm vs @ vs torch.matmul

操作适用场景输入要求
torch.bmm严格 3D batch 矩阵乘(B,n,m) @ (B,m,k)
@ / matmul任意维度，自动广播最后两维是矩阵

本题 Q/K/V 是 3D，两者均可；torch.bmm 语义更明确。

注意：K.transpose(1, 2) 交换 seq 和 d_k 维， 得到 (B, d_k, S_k)，与 Q 相乘后得分矩阵 (B, S_q, S_k)。

测验

Q1 · 形状追踪

Q: (2, 4, 8), K: (2, 6, 8)，scores = torch.bmm(Q, K.transpose(1,2)) 的 shape？

  • A (2, 8, 8)
  • B (2, 6, 4)
  • C (2, 4, 6)
  • D (2, 8, 6)

Q2 · 缩放的作用

为什么要除以 √d_k？

  • A 让输出值在 (0, 1) 之间
  • B 防止大 d_k 时点积过大导致 softmax 饱和
  • C 和 LayerNorm 保持一致
  • D 节省计算量

Q3 · softmax 维度

scores: (B, S_q, S_k)，应对哪个维度做 softmax？

  • A dim=-1（S_k，对所有 key 归一化）
  • B dim=1（S_q，对所有 query 归一化）
  • C dim=0（batch 维）
  • D 所有维度一起

参考解法

import math, torch

def scaled_dot_product_attention(Q, K, V):
    d_k     = K.size(-1)
    scores  = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(d_k)
    weights = torch.softmax(scores, dim=-1)
    return torch.bmm(weights, V)
