第 22 课Hard

2D 卷积

用 unfold + einsum 手写卷积，理解 im2col 本质。

学习目标

  • 理解卷积 = 滑动窗口点积
  • 掌握 im2col（unfold）将卷积转矩阵乘法
  • 能写出支持 stride 和 padding 的 Conv2D

核心概念：im2col

# 卷积的直觉：
# 对图像每个位置，取 (C_in, kH, kW) 的小块，与权重做点积
# 这等价于：将所有小块"展开"成行矩阵，与权重矩阵相乘

# im2col 步骤：
# 1. unfold：将输入按卷积核大小展开
#    输入: (B, C_in, H, W)
#    展开: (B, C_in*kH*kW, L)  L = 输出位置数
# 2. 矩阵乘法：与权重 (C_out, C_in*kH*kW) 相乘
# 3. reshape：(B, C_out, H_out, W_out)

输出尺寸计算

H_out = (H + 2*padding - kH) // stride + 1
W_out = (W + 2*padding - kW) // stride + 1

PyTorch 实现

class Conv2d(nn.Module):
    def __init__(self, in_channels, out_channels, kernel_size,
                 stride=1, padding=0):
        super().__init__()
        self.stride  = stride
        self.padding = padding
        kH = kW = kernel_size
        self.weight = nn.Parameter(
            torch.randn(out_channels, in_channels, kH, kW) * 0.01
        )
        self.bias = nn.Parameter(torch.zeros(out_channels))

    def forward(self, x):
        B, C_in, H, W = x.shape
        kH, kW = self.weight.shape[2:]
        H_out = (H + 2*self.padding - kH) // self.stride + 1
        W_out = (W + 2*self.padding - kW) // self.stride + 1

        # im2col: 展开为 (B, C_in*kH*kW, H_out*W_out)
        x_unf = F.unfold(x, kernel_size=(kH, kW),
                         stride=self.stride, padding=self.padding)

        # 权重展开: (C_out, C_in*kH*kW)
        w_flat = self.weight.view(self.weight.size(0), -1)

        # 矩阵乘: (B, C_out, H_out*W_out)
        out = w_flat @ x_unf + self.bias.view(-1, 1)

        return out.view(B, -1, H_out, W_out)

  • B (B, C*k*k, H_out*W_out)

  • A 30

Q3 · im2col 目的

im2col 将卷积转成矩阵乘法的主要目的是？

  • A 利用高度优化的 BLAS 矩阵乘法加速计算
  • B 减少参数量
  • C 支持任意 stride
  • D 避免 padding 操作

面试要点

  • im2col：F.unfold → 矩阵乘 → reshape
  • unfold 输出：(B, C*kH*kW, H_out*W_out)
  • 输出尺寸：(H + 2p - k) // s + 1
  • 内存代价：unfold 展开后内存是原来 kH*kW 倍
