混合专家（MoE）

稀疏激活：Router 选 top-k 专家，只运行被选中的专家。

学习目标

  • 理解 MoE 如何用稀疏激活扩大模型容量
  • 掌握 top-k 路由器 + 专家加权求和的实现
  • 理解负载均衡的重要性

核心概念

MoE 结构

# 有 E 个专家（每个是独立的 MLP）
# Router：决定每个 token 去哪些专家
# top-k：每个 token 只激活 k 个专家

# 前向：
# 1. router_logits = W_router @ x    # (B*S, E)
# 2. weights, indices = topk(router_logits, k)
# 3. weights = softmax(weights)       # 专家权重
# 4. out = Σ_i weights[i] * expert[indices[i]](x)

稀疏性的好处

E=8 个专家，每次只激活 k=2 个：参数量是密集模型的 8x， 但计算量只有 2/8=25% 增加（路由开销）→ 高效扩大模型容量。

PyTorch 实现

class MoE(nn.Module):
    def __init__(self, d_model, num_experts=8, top_k=2, ffn_dim=None):
        super().__init__()
        self.top_k = top_k
        if ffn_dim is None:
            ffn_dim = 4 * d_model
        self.router = nn.Linear(d_model, num_experts, bias=False)
        self.experts = nn.ModuleList([
            nn.Sequential(
                nn.Linear(d_model, ffn_dim),
                nn.GELU(),
                nn.Linear(ffn_dim, d_model)
            ) for _ in range(num_experts)
        ])

    def forward(self, x):
        B, S, D = x.shape
        x_flat = x.view(-1, D)   # (B*S, D)

        router_logits = self.router(x_flat)  # (B*S, E)
        weights, indices = torch.topk(router_logits, self.top_k, dim=-1)
        weights = torch.softmax(weights, dim=-1)  # (B*S, k)

        out = torch.zeros_like(x_flat)
        for i, expert in enumerate(self.experts):
            mask = (indices == i).any(dim=-1)   # 被选中的 token
            if not mask.any():
                continue
            # 该专家处理的 token
            expert_input = x_flat[mask]
            expert_out   = expert(expert_input)
            # 找到对应权重
            expert_weight = weights[mask] * (indices[mask] == i).float()
            out[mask] += (expert_out * expert_weight.sum(dim=-1, keepdim=True))

        return out.view(B, S, D)

参考解法

class MoE(nn.Module):
    def forward(self, x):
        B, S, D = x.shape
        x_flat = x.view(-1, D)
        router_logits = self.router(x_flat)
        weights, indices = torch.topk(router_logits, self.top_k, dim=-1)
        weights = torch.softmax(weights, dim=-1)   # (B*S, k)
        out = torch.zeros_like(x_flat)
        for i, expert in enumerate(self.experts):
            # 找这个 expert 对应的 token 和权重
            mask = (indices == i)                  # (B*S, k)
            token_mask = mask.any(dim=-1)           # (B*S,)
            if not token_mask.any():
                continue
            w = (mask * weights)[token_mask].sum(-1, keepdim=True)
            out[token_mask] += w * expert(x_flat[token_mask])
        return out.view(B, S, D)

面试要点

  • 结构：Router（线性）+ E 个专家 MLP + top-k 选择
  • 权重：softmax(top-k logits)，加权求和专家输出
  • 稀疏性：每 token 只跑 k/E 比例的专家
  • 代表模型：Mixtral 8×7B（k=2, E=8），GPT-4（推测 MoE）
