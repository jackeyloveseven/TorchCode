Top-k / Top-p 采样

控制生成多样性：只从最高概率的 k 个 token（或概率累积 p）中采样。

学习目标

  • 理解 top-k 和 top-p（nucleus）采样的区别
  • 掌握用 -inf 掩码截断低概率 token 的技巧
  • 理解 temperature 缩放的作用

核心概念

贪心 vs 采样

greedy: next = argmax(logits)        # 确定性，常重复
sample: next = multinomial(softmax)  # 随机，可能低质

# 平衡方案：只在高概率 token 中随机采样

Top-k vs Top-p

# Top-k：保留概率最高的 k 个 token
kth_val = logits.topk(k).values.min()
logits[logits < kth_val] = -inf    # 截断尾部

# Top-p（Nucleus Sampling）：保留概率累积到 p 的 token
sorted_probs = softmax(logits).sort(descending=True)
cumsum = sorted_probs.cumsum(0)
remove_idx = cumsum > p              # 超过 p 的截断
logits[remove_idx] = -inf

Temperature

logits = logits / temperature
# temperature < 1 → 分布变尖锐（保守，质量高）
# temperature > 1 → 分布变平坦（多样性高）
# temperature = 0 → 等同贪心（argmax）

PyTorch 实现

def topk_sampling(logits, k=50, p=0.9, temperature=1.0):
    # logits: (vocab_size,)
    logits = logits / max(temperature, 1e-8)

    # Top-k 截断
    if k > 0:
        topk_vals = torch.topk(logits, k).values
        logits[logits < topk_vals[-1]] = float('-inf')

    # Top-p 截断（nucleus sampling）
    if p < 1.0:
        probs = torch.softmax(logits, dim=-1)
        sorted_probs, sorted_idx = torch.sort(probs, descending=True)
        cumprobs = torch.cumsum(sorted_probs, dim=0)
        remove = cumprobs - sorted_probs > p   # 保留首个超过 p 的 token
        sorted_idx_remove = sorted_idx[remove]
        logits[sorted_idx_remove] = float('-inf')

    # 从剩余 token 中采样
    probs = torch.softmax(logits, dim=-1)
    return torch.multinomial(probs, num_samples=1).item()

测验

Q1 · Top-k vs Top-p

Top-p（Nucleus）采样与 Top-k 的核心区别是？

  • A Top-p 更快，Top-k 更准
  • B Top-p 的 k 是动态的（基于概率累积），Top-k 固定
  • C Top-p 用于训练，Top-k 用于推理
  • D Top-p 不需要 temperature

Q2 · Temperature

temperature=0.5 vs temperature=2.0，生成有什么区别？

  • A temperature=0.5 更随机
  • B 无区别，temperature 不影响概率分布
  • C temperature=0.5 更保守（分布尖锐），temperature=2.0 更随机
  • D temperature=2.0 更保守

Q3 · 截断实现

为什么用 float('-inf') 而不是 -1e10 来截断 logits？

  • A -inf 经 softmax 后精确变为 0，-1e10 可能有微小误差
  • B -inf 计算更快
  • C -1e10 可能导致溢出
  • D 两者等价，只是风格问题

参考解法

def topk_sampling(logits, k=50, p=0.9, temperature=1.0):
    logits = logits / max(temperature, 1e-8)
    # Top-k
    if k > 0:
        logits[logits < logits.topk(k).values[-1]] = float('-inf')
    # Top-p
    if p < 1.0:
        probs = logits.softmax(-1)
        sorted_probs, sorted_idx = probs.sort(descending=True)
        cumsum = sorted_probs.cumsum(0)
        remove = (cumsum - sorted_probs) > p
        logits[sorted_idx[remove]] = float('-inf')
    return torch.multinomial(logits.softmax(-1), 1).item()

面试要点

  • Top-k：保留最高 k 个，其余 -inf
  • Top-p：保留概率累积 ≤ p 的最小集合
  • Temperature：logits/t，t<1 保守，t>1 随机
  • 采样：torch.multinomial(probs, 1)
