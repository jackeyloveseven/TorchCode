线性回归

三种实现：解析解、梯度下降、nn.Linear，理解 PyTorch 训练循环。

学习目标

  • 理解线性回归的三种 PyTorch 实现方式
  • 掌握完整的训练循环（forward → loss → backward → step）
  • 能比较解析解和梯度下降的适用场景

核心概念

三种实现方式

# 方法 1：解析解（正规方程）
# W = (X^T X)^{-1} X^T y
# 优点：精确；缺点：O(D³) 矩阵求逆，D 大时慢

# 方法 2：梯度下降
# loss = MSE(X@w + b, y)
# 每步：w -= lr * grad_w

# 方法 3：nn.Linear + optimizer（推荐）
# 利用 PyTorch autograd

PyTorch 实现

# 方法 1：解析解
def linear_regression_normal_eq(X, y):
    # X: (N, D), y: (N,)
    W = torch.linalg.lstsq(X, y).solution
    return W

# 方法 2：梯度下降（手动）
def linear_regression_gd(X, y, lr=0.01, epochs=1000):
    N, D = X.shape
    w = torch.zeros(D, requires_grad=True)
    b = torch.zeros(1, requires_grad=True)
    for _ in range(epochs):
        pred = X @ w + b
        loss = ((pred - y) ** 2).mean()
        loss.backward()
        with torch.no_grad():
            w -= lr * w.grad; w.grad.zero_()
            b -= lr * b.grad; b.grad.zero_()
    return w.detach(), b.detach()

# 方法 3：nn.Linear（推荐）
def linear_regression_nn(X, y, lr=0.01, epochs=200):
    model     = nn.Linear(X.shape[1], 1)
    optimizer = torch.optim.SGD(model.parameters(), lr=lr)
    for _ in range(epochs):
        optimizer.zero_grad()
        loss = F.mse_loss(model(X).squeeze(), y)
        loss.backward()
        optimizer.step()
    return model

测验

Q1 · 解析解局限

解析解（正规方程）在什么情况下不适用？

  • A 样本量太大时
  • B 损失不是 MSE 时
  • C 特征维度 D 很大时（矩阵求逆 O(D³)）
  • D 数据有噪声时

Q2 · 训练循环顺序

PyTorch 标准训练循环的正确顺序是？

  • A forward → backward → zero_grad → step
  • B zero_grad → forward → loss → backward → step
  • C forward → zero_grad → backward → step
  • D backward → forward → step → zero_grad

Q3 · MSE 定义

Mean Squared Error (MSE) 的公式是？

  • A mean((pred - y)²)
  • B mean(abs(pred - y))
  • C sum((pred - y)²)
  • D -mean(y * log(pred))

参考解法

# 解析解
def normal_equation(X, y):
    return torch.linalg.lstsq(X, y).solution

# 梯度下降
def grad_descent(X, y, lr=0.01, epochs=1000):
    w = torch.zeros(X.shape[1], requires_grad=True)
    b = torch.zeros(1, requires_grad=True)
    for _ in range(epochs):
        loss = F.mse_loss((X @ w + b).squeeze(), y)
        loss.backward()
        with torch.no_grad():
            w -= lr * w.grad; w.grad.zero_()
            b -= lr * b.grad; b.grad.zero_()
    return w.detach(), b.detach()

面试要点

  • 解析解：lstsq(X, y)，精确但 O(D³)
  • 梯度下降：loss.backward() → w -= lr * grad
  • 训练循环：zero_grad → forward → loss → backward → step
  • with no_grad：原地更新参数时需要，避免跟踪梯度
