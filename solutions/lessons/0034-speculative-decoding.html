第 34 课Hard

推测解码

小模型起草，大模型验证：并行验证多个 token，输出分布不变。

学习目标

  • 理解推测解码如何加速自回归生成
  • 掌握接受-拒绝采样（accept/reject）机制
  • 理解为什么输出分布与大模型单独生成相同

核心概念

算法思路

# 关键洞察：
# - 大模型（target）每步只生成 1 token，速度慢
# - 小模型（draft）很快，但质量低
# - 用小模型生成 k 个 token 草稿
# - 大模型一次 forward 验证所有 k 个 token（并行！）
# - 按概率比接受/拒绝：p_target / p_draft

# 接受条件：
# r = uniform(0, 1)
# if r < min(1, p_target(x_i) / p_draft(x_i)):
#     accept（保留草稿 token）
# else:
#     reject（从修正分布采样新 token，后面的草稿全丢）

修正分布（保证分布无偏）

# 拒绝时，从 p_corrected 采样：
p_corrected(x) = normalize(max(0, p_target(x) - p_draft(x)))
# 这保证最终输出分布 = p_target（数学上可证明）

PyTorch 实现

def speculative_step(draft_probs, target_probs, draft_token):
    # draft_probs, target_probs: (vocab_size,) 概率分布
    # draft_token: 草稿模型采样的 token id
    p_d = draft_probs[draft_token]
    p_t = target_probs[draft_token]

    # 接受-拒绝
    r = torch.rand(1).item()
    if r < min(1.0, (p_t / (p_d + 1e-10)).item()):
        return draft_token, True   # 接受
    else:
        # 从修正分布采样
        corrected = torch.clamp(target_probs - draft_probs, min=0)
        corrected = corrected / corrected.sum()
        new_token = torch.multinomial(corrected, 1).item()
        return new_token, False    # 拒绝，用修正 token
加速效果：平均接受率 α 越高，加速越大。 如果 draft 和 target 分布接近，α→1，k 个草稿几乎全被接受， 相当于每次大模型 forward 产出 k 个 token（≈ k 倍加速）。

参考解法

def speculative_step(draft_probs, target_probs, draft_token):
    p_d = draft_probs[draft_token]
    p_t = target_probs[draft_token]
    r   = torch.rand(1).item()
    if r < min(1.0, (p_t / (p_d + 1e-10)).item()):
        return draft_token, True
    # 修正分布
    corrected = torch.clamp(target_probs - draft_probs, min=0)
    corrected = corrected / (corrected.sum() + 1e-10)
    return torch.multinomial(corrected, 1).item(), False

面试要点

  • 流程：draft 生成 k 个→target 并行验证→按比率接受/拒绝
  • 接受率：min(1, p_target/p_draft)
  • 修正分布：max(0, p_t - p_d)，保证输出分布无偏
  • 加速：平均接受率越高，越接近 k 倍加速
