BPE 分词

统计字符对频率，不断合并最频繁的对，构建词表。

学习目标

  • 理解 BPE 的贪心合并策略
  • 掌握字符对统计和合并的步骤
  • 能手写 BPE 训练的核心循环

核心概念

BPE 训练步骤

# 初始：每个单词分成字符序列（+结尾标记）
# "low" → ['l', 'o', 'w', '</w>']
# "lower" → ['l', 'o', 'w', 'e', 'r', '</w>']

# 每轮：
# 1. 统计所有相邻字符对的频次（跨单词边界不计）
# 2. 找到频次最高的对，将其合并
# 3. 更新词表（合并后的子词算一个单元）
# 重复 vocab_size - initial_chars 次

示例

初始：{'l o w </w>': 5, 'l o w e r </w>': 2, 'n e w e r </w>': 6}
第 1 轮：最频繁对 = ('e', 'r') 出现 8 次
合并后：{'l o w </w>': 5, 'l o w er </w>': 2, 'n e w er </w>': 6}
第 2 轮：最频繁对 = ('w', 'er') 出现 8 次
...

PyTorch 实现

from collections import Counter

def get_pairs(vocab):
    pairs = Counter()
    for word, freq in vocab.items():
        symbols = word.split()
        for i in range(len(symbols) - 1):
            pairs[(symbols[i], symbols[i+1])] += freq
    return pairs

def merge_pair(pair, vocab):
    new_vocab = {}
    bigram = ' '.join(pair)
    replacement = ''.join(pair)
    for word, freq in vocab.items():
        new_word = word.replace(bigram, replacement)
        new_vocab[new_word] = freq
    return new_vocab

def bpe_train(corpus, num_merges):
    # 初始化：字符级 vocab
    vocab = Counter()
    for word in corpus.split():
        vocab[' '.join(list(word) + ['</w>'])] += 1

    merges = []
    for _ in range(num_merges):
        pairs = get_pairs(vocab)
        if not pairs:
            break
        best = pairs.most_common(1)[0][0]
        vocab = merge_pair(best, vocab)
        merges.append(best)
    return vocab, merges

参考解法

def get_pairs(vocab):
    pairs = Counter()
    for word, freq in vocab.items():
        syms = word.split()
        for i in range(len(syms)-1):
            pairs[(syms[i], syms[i+1])] += freq
    return pairs

def merge_pair(pair, vocab):
    bigram = ' '.join(pair)
    merged = ''.join(pair)
    return {w.replace(bigram, merged): f for w, f in vocab.items()}

def bpe_train(corpus, num_merges):
    vocab = Counter(' '.join(list(w) + ['</w>']) for w in corpus.split())
    merges = []
    for _ in range(num_merges):
        pairs = get_pairs(vocab)
        if not pairs: break
        best = pairs.most_common(1)[0][0]
        vocab = merge_pair(best, vocab)
        merges.append(best)
    return vocab, merges

面试要点

  • 核心循环：统计对频率 → 合并最频繁对 → 重复
  • </w>：词尾标记，防止跨词合并
  • num_merges：决定最终词表大小（初始字符数 + merges）
  • 代表应用：GPT-2（50k BPE），LLaMA（SentencePiece BPE）
