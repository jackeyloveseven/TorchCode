交叉熵损失

从 logits 到损失：log-sum-exp 数值稳定版，精通它才能理解语言模型训练。

学习目标

  • 理解交叉熵 = 负对数似然（NLL）
  • 掌握 log-softmax + NLL 的数值稳定实现
  • 能手写 cross_entropy(logits, targets)

核心概念

公式推导

# 标准定义
CE = -Σ_c y_c * log(p_c)     # y_c 是 one-hot，p_c 是概率
   = -log(p_{target})         # 只有正确类贡献

# p_{target} = softmax(logits)[target]
#            = exp(z_{target}) / Σ_c exp(z_c)

# 所以：
CE = -z_{target} + log(Σ_c exp(z_c))
   = logsumexp(z) - z_{target}

数值稳定 log-sum-exp

# 直接 log(sum(exp(z))) 会数值溢出（z 很大时）
# 稳定版：减去最大值
m = z.max(dim=-1, keepdim=True).values
log_sum_exp = m.squeeze(-1) + (z - m).exp().sum(dim=-1).log()

PyTorch 实现

def cross_entropy(logits, targets):
    # logits: (N, C)，targets: (N,) 整数类别
    # 数值稳定：减去 max
    m   = logits.max(dim=-1, keepdim=True).values
    log_sum_exp = (logits - m).exp().sum(dim=-1).log() + m.squeeze(-1)
    # 正确类的 logit
    correct_logits = logits[torch.arange(len(targets)), targets]
    loss = log_sum_exp - correct_logits
    return loss.mean()
等价写法：F.cross_entropy(logits, targets) 内部就是 log_softmax + nll_loss，和上面等价。 面试中可以直接用，但要能解释原理。

测验

Q1 · 公式

交叉熵损失（对单个样本，正确类索引为 t）等于？

  • A softmax(z)[t]
  • B logsumexp(z) - z[t]
  • C z[t] - logsumexp(z)
  • D -z[t]

Q2 · 数值稳定

为什么 logsumexp 要减去 max？

  • A 加快计算速度
  • B 保证结果在 [0, 1] 范围
  • C 防止 exp 数值溢出（overflow）
  • D 等价于 batch normalization

Q3 · 高级索引

logits[torch.arange(N), targets] 的作用是？

  • A 提取每个样本对应正确类的 logit（形状 (N,)）
  • B 提取 targets 列的所有行
  • C 将 logits 按 targets 排序
  • D 报错，索引形状不匹配

参考解法

def cross_entropy(logits, targets):
    m   = logits.max(dim=-1, keepdim=True).values
    lse = (logits - m).exp().sum(dim=-1).log() + m.squeeze(-1)
    correct = logits[torch.arange(len(targets)), targets]
    return (lse - correct).mean()

面试要点

  • 公式：loss = logsumexp(z) - z[target]
  • 稳定技巧：减去 max 再做 exp，等价但无溢出
  • 索引：logits[arange(N), targets] 提取正确类 logit
  • 均值：最后 .mean()，对 batch 平均
