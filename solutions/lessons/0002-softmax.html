实现 Softmax

把一组实数变成概率分布——以及为什么朴素实现会炸成 NaN。

学习目标

  • 理解 softmax 将 logits 转为概率分布的数学原理
  • 掌握数值稳定性技巧：为什么要减去 max
  • 理解 keepdim=True 与广播的配合
  • 知道 .max() 返回的是 named tuple

Softmax 是什么？

神经网络分类任务的最后一层通常输出一组实数（logits）， 比如 [2.1, 0.5, -0.3]。这些数字本身没有"概率"的含义——可能是负数、超过 1。

Softmax 把它们变成和为 1 的概率分布，让每个值都在 (0, 1) 之间： 

logits:       [2.1,  0.5, -0.3]
softmax:      [0.72, 0.19, 0.09]   # 和 = 1.0

直觉：指数函数放大差距，归一化保证和为 1。最大的 logit 会获得最高的概率， 差距越大，概率越集中。

数学定义

softmax(xi) = exp(xi) / Σj exp(xj)

验算一下 [1., 2., 3.]：

exp([1, 2, 3]) = [2.718, 7.389, 20.086]
sum            = 30.193
softmax        = [0.0900, 0.2447, 0.6652]  # 和 = 1.0 ✓
关键性质：softmax 输出的每个值都 > 0，且所有值之和 = 1， 满足概率分布的定义。

⚠️ 核心难点：数值稳定性

朴素实现会炸

# ❌ 朴素实现
def naive_softmax(x):
    return torch.exp(x) / torch.exp(x).sum()

对 [1., 2., 3.] 没问题。但如果 x 较大：

x = torch.tensor([1000., 1001., 1002.])
torch.exp(x)   # tensor([inf, inf, inf])  ← float32 溢出！
inf / inf      # nan ← 结果全是 NaN

float32 的最大值约 3.4×1038，而 exp(89) ≈ 4.6×1038， x 超过约 88 就溢出成 inf。

稳定技巧：先减去 max(x)

softmax(xi) = exp(xi − max(x)) / Σj exp(xj − max(x))

为什么结果一样？设 c = max(x)，分子分母同乘 exp(-c)： 

  exp(x_i - c)          exp(x_i) · exp(-c)       exp(x_i)
──────────────────  =  ──────────────────────  =  ──────────────
Σ exp(x_j - c)         Σ exp(x_j) · exp(-c)      Σ exp(x_j)

分子分母都乘了同一个常数，结果不变。

减去 max 之后，指数参数最大为 0（exp(0) = 1），其余都是负数，永远不会溢出：

x = tensor([1000., 1001., 1002.])
x - max(x) = tensor([-2., -1., 0.])   # 安全！
torch.exp([-2., -1., 0.]) = tensor([0.135, 0.368, 1.000])
softmax = tensor([0.090, 0.245, 0.665])  # 正确 ✓

PyTorch 实现

完整代码

def my_softmax(x: torch.Tensor, dim: int = -1) -> torch.Tensor:
    x_max = x.max(dim=dim, keepdim=True).values   # ① 求 max，保持维度
    e_x   = torch.exp(x - x_max)                  # ② 稳定的 exp
    return e_x / e_x.sum(dim=dim, keepdim=True)   # ③ 归一化

① .max(dim=dim, keepdim=True) 是什么？

tensor.max(dim=d) 返回 named tuple，包含两个字段： .values（最大值）和 .indices（下标）。 

x = torch.tensor([[1., 3., 2.],
                   [5., 0., 4.]])

x.max(dim=-1)
# torch.return_types.max(
#   values=tensor([3., 5.]),    ← shape (2,)
#   indices=tensor([1, 0])
# )

x.max(dim=-1, keepdim=True).values
# tensor([[3.], [5.]])          ← shape (2, 1)

② 为什么必须 keepdim=True？

这是广播（broadcasting）的需要。

x     shape: (4, 8)
x_max shape: (4,)    ← keepdim=False，减法失败！形状不对齐
x_max shape: (4, 1)  ← keepdim=True，(4,1) 会广播到 (4,8) ✓
规则：对某个 dim 做 reduce（max/sum/mean）， 如果后面还要用这个结果和原 tensor 做运算，几乎总是需要 keepdim=True。 
# 验证
x = torch.tensor([1.0, 2.0, 3.0])
out = my_softmax(x, dim=-1)
print(out)           # tensor([0.0900, 0.2447, 0.6652])
print(out.sum())     # tensor(1.0000)  ✓

# 大值测试
x_big = torch.tensor([1000., 1001., 1002.])
print(my_softmax(x_big, dim=-1))
# tensor([0.0900, 0.2447, 0.6652])  ✓ 不再 NaN

参考解法

import torch

def my_softmax(x: torch.Tensor, dim: int = -1) -> torch.Tensor:
    x_max = x.max(dim=dim, keepdim=True).values
    e_x   = torch.exp(x - x_max)
    return e_x / e_x.sum(dim=dim, keepdim=True)
三行，三个关键点：
1. .max(...).values —— 取 named tuple 的值
2. x - x_max —— 数值稳定性（减 max）
3. keepdim=True 出现两次 —— 保证广播正确

面试要点总结

  • 定义：exp(x_i) / Σ exp(x_j)，输出和为 1
  • 稳定版：先减 max(x)，数学等价但不溢出
  • 实现：x.max(dim=dim, keepdim=True).values
  • 广播：reduce 后做运算，记得 keepdim=True
  • 延伸：log_softmax = x - x_max - log(Σ exp(x-x_max))，数值更稳定，常用于交叉熵
