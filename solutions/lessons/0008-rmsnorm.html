实现 RMSNorm

LLaMA/Gemma 的归一化选择——去掉均值，只除 RMS，更简洁更快。

学习目标

  • 理解 RMSNorm 和 LayerNorm 的区别（去掉减均值步骤）
  • 掌握 x.pow(2).mean() 计算均方根
  • 理解为什么 LLM 更偏爱 RMSNorm

核心概念

RMSNorm(x) = x / RMS(x) · w，其中 RMS(x) = √(mean(x²) + ε)

与 LayerNorm 的对比

LayerNormRMSNorm
减均值是（中心化）否
除以√(var + ε)√(mean(x²) + ε)
可学习参数γ（scale）+ β（shift）w（scale 只）
代表模型BERT, GPT-2LLaMA, Gemma, Mistral

RMSNorm 省略了减均值的计算，在实践中效果相当，但速度更快（约快 7~15%）。

PyTorch 实现

def rms_norm(x, weight, eps=1e-6):
    rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + eps)
    return x / rms * weight
两行，三步：①平方 → ②均值 → ③开方，得到 RMS；然后除以 RMS，乘以可学习 weight。 keepdim=True 保证广播正确。

ε 的作用

当 x 全为 0 时，RMS=0，除法会得到 NaN 或 inf。ε（默认 1e-6）防止分母为 0。 注意 RMSNorm 通常用更小的 ε（1e-6）而不是 LayerNorm 的 1e-5。

测验

Q1 · 核心区别

RMSNorm 相比 LayerNorm 省略了什么？

  • A 可学习的 scale 参数

  • D ε 数值稳定项

Q2 · 计算

x.pow(2).mean(dim=-1) 计算的是什么？

  • A x 的方差（var）
  • B x 的标准差（std）
  • C x 的均方值（mean of squares）
  • D x 的绝对均值（mean of abs）

Q3 · 可学习参数

RMSNorm 有哪些可学习参数？

  • A 只有 w（scale），没有 β（shift）
  • B γ（scale）和 β（shift）
  • C 没有可学习参数
  • D 只有 β（shift），没有 scale

参考解法

def rms_norm(x, weight, eps=1e-6):
    rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + eps)
    return x / rms * weight

面试要点

  • 公式：x / √(mean(x²) + ε) * w
  • 与 LayerNorm 的区别：不减均值，只除 RMS，无 β 参数
  • 使用场景：LLaMA、Gemma、Mistral 等现代 LLM
  • ε：RMSNorm 通常用 1e-6，LayerNorm 用 1e-5
