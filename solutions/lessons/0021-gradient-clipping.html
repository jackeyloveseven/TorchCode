梯度裁剪

防止梯度爆炸：计算全局范数，按比例缩放所有梯度。

学习目标

  • 理解梯度爆炸问题及其原因
  • 掌握全局 L2 范数裁剪的算法
  • 能手写 clip_grad_norm_(parameters, max_norm)

核心概念

全局 L2 范数裁剪

# 步骤：
# 1. 计算所有参数梯度的 L2 范数之和（全局范数）
# total_norm = sqrt(Σ_p Σ_i g_p_i²)

# 2. 如果 total_norm > max_norm，等比缩放所有梯度
# clip_coef = max_norm / total_norm
# for each param p: p.grad *= clip_coef

为什么用全局范数而不是逐参数？

逐参数裁剪会改变梯度方向；全局裁剪只缩小步长，保持梯度方向不变。

PyTorch 实现

def clip_grad_norm_(parameters, max_norm):
    # parameters: list of nn.Parameter
    params_with_grad = [p for p in parameters if p.grad is not None]
    # 计算全局 L2 范数
    total_norm = torch.sqrt(
        sum(p.grad.data.pow(2).sum() for p in params_with_grad)
    )
    # 按比例裁剪
    clip_coef = max_norm / (total_norm + 1e-6)
    if clip_coef < 1:   # 只在超出时裁剪
        for p in params_with_grad:
            p.grad.data.mul_(clip_coef)
    return total_norm
监控 total_norm：训练 LLM 时，通常记录 grad_norm 到日志中。 norm 突然激增 → 梯度爆炸 → 需要调小 lr 或增大 max_norm。 GPT-2/LLaMA 训练通常设 max_norm=1.0。

测验

Q1 · 全局范数

梯度裁剪中的"全局范数"是怎么计算的？

  • A 所有梯度的最大值
  • B 各参数梯度范数的平均值
  • C sqrt(所有参数梯度的平方和)
  • D 各参数梯度范数的最大值

全局 L2 范数裁剪（与逐参数裁剪相比）的优势是？

  • A 计算速度更快
  • B 保持梯度方向不变（等比缩放）
  • C 完全消除梯度爆炸
  • D 节省显存

Q3 · 何时裁剪

如果 total_norm=0.5，max_norm=1.0，应该裁剪梯度吗？

  • A 不裁剪（total_norm < max_norm，clip_coef > 1）
  • B 裁剪到 0.5（乘以 1.0/0.5 = 2）
  • C 裁剪，clip_coef = 0.5
  • D 裁剪到 0（所有梯度置零）

参考解法

def clip_grad_norm_(parameters, max_norm):
    params = [p for p in parameters if p.grad is not None]
    total_norm = torch.sqrt(sum(p.grad.data.pow(2).sum() for p in params))
    clip_coef  = max_norm / (total_norm + 1e-6)
    if clip_coef < 1:
        for p in params:
            p.grad.data.mul_(clip_coef)
    return total_norm

面试要点

  • 步骤：计算全局 L2 范数 → 超出则等比缩放所有梯度
  • clip_coef：max_norm / total_norm，只在 <1 时生效
  • 保持方向：等比缩放不改变梯度向量方向
  • PyTorch 内置：torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
