PPO 损失

截断替代目标：min(r*A, clip(r)*A)，防止策略更新过大。

学习目标

  • 理解 PPO-Clip 截断目标的动机
  • 掌握 ratio = π_new/π_old 的计算
  • 能手写 PPO 的 clipped surrogate objective

核心概念

PPO 的问题背景

# 策略梯度基本形式：
# loss = -E[log π(a|s) * A]  (朴素)
# 问题：一步更新太大 → 策略崩溃

# PPO 用重要性采样比率衡量更新量：
# ratio r_t = π_new(a_t|s_t) / π_old(a_t|s_t)
#           = exp(logp_new - logp_old)
# r_t > 1 → 新策略更喜欢这个动作
# r_t < 1 → 新策略不太喜欢

截断目标（PPO-Clip）

L_clip = -E[min(r_t * A_t, clip(r_t, 1-ε, 1+ε) * A_t)]
# A_t > 0（好动作）：限制最大提升 → 不能过于激进
# A_t < 0（坏动作）：限制最大降低 → 不过快惩罚

PyTorch 实现

def ppo_loss(log_probs_new, log_probs_old, advantages,
             clip_eps=0.2, value_coef=0.5, entropy_coef=0.01):
    # log_probs: (B,) 各时间步的 log π(a|s)
    # advantages: (B,) 优势函数估计（已归一化）

    ratios = (log_probs_new - log_probs_old.detach()).exp()

    # PPO-Clip 策略损失
    surr1 = ratios * advantages
    surr2 = ratios.clamp(1 - clip_eps, 1 + clip_eps) * advantages
    policy_loss = -torch.min(surr1, surr2).mean()

    return policy_loss
完整 PPO：除策略损失外，还有 value loss（MSE，让 critic 准确预测回报） 和 entropy bonus（鼓励探索）。总损失 = policy_loss + c1*value_loss - c2*entropy。

测验

Q1 · Ratio 计算

PPO 中 ratio r_t 的计算公式是？

  • A log_new - log_old
  • B exp(log_new - log_old)
  • C log_new / log_old
  • D softmax(log_new - log_old)

Q2 · Clip 的含义

min(r*A, clip(r, 1-ε, 1+ε)*A) 中 min 的作用是？

  • A 取较大值（乐观估计）
  • B 只使用截断后的 ratio
  • C 取悲观下界（防止 A>0 时过度优化，A<0 时过度惩罚）
  • D 用于数值稳定性

Q3 · 完整 PPO

除策略损失外，PPO 还包含哪些损失项？

  • A Value 损失（Critic）+ Entropy bonus（鼓励探索）
  • B 只有策略损失（无其他项）
  • C KL 散度（固定权重）
  • D L2 正则化

参考解法

def ppo_loss(log_probs_new, log_probs_old, advantages, clip_eps=0.2):
    ratios = (log_probs_new - log_probs_old.detach()).exp()
    surr1 = ratios * advantages
    surr2 = ratios.clamp(1 - clip_eps, 1 + clip_eps) * advantages
    return -torch.min(surr1, surr2).mean()

面试要点

  • ratio：exp(logp_new - logp_old)
  • clip：clamp(ratio, 1-ε, 1+ε)，限制更新幅度
  • min：两个 surrogate 取最小，悲观下界
  • 完整损失：policy + c1*value - c2*entropy
