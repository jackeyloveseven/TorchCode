ViT Patch Embedding

图像切块 → 线性投影：用 unfold 或 Conv2D 将图片变成 token 序列。

学习目标

  • 理解 ViT 如何将图片转为 token 序列
  • 掌握 unfold 切块 + 线性投影的实现
  • 理解 [CLS] token 和位置编码的作用

核心概念

ViT 的输入流程

# 图像: (B, C, H, W)
# 步骤：
# 1. 切块：将图像分成 P×P 的 patch
#    每个 patch 的维度：C * P * P
#    patch 数量：N = (H/P) * (W/P)
# 2. 线性投影：每个 patch 投影到 d_model 维
#    输出形状：(B, N, d_model)
# 3. 加 CLS token（可选）：(B, N+1, d_model)
# 4. 加位置编码：(B, N+1, d_model)

两种实现方式

# 方法 1：unfold + linear（显式）
x_patches = x.unfold(2, P, P).unfold(3, P, P)  # 切块
x_flat = x_patches.reshape(B, -1, C*P*P)        # 展平

# 方法 2：Conv2d，kernel=P，stride=P（等价）
proj = nn.Conv2d(C, d_model, kernel_size=P, stride=P)
out = proj(x).flatten(2).transpose(1, 2)  # (B, N, d_model)

PyTorch 实现

class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16,
                 in_channels=3, d_model=768):
        super().__init__()
        self.patch_size = patch_size
        num_patches = (img_size // patch_size) ** 2

        # Conv2d 等价于 unfold + linear
        self.proj = nn.Conv2d(
            in_channels, d_model,
            kernel_size=patch_size, stride=patch_size
        )
        # CLS token（可学习）
        self.cls_token = nn.Parameter(torch.zeros(1, 1, d_model))
        # 位置编码（num_patches + 1 个 cls）
        self.pos_embed = nn.Parameter(
            torch.zeros(1, num_patches + 1, d_model)
        )

    def forward(self, x):
        B = x.shape[0]
        # (B, d_model, H/P, W/P) → (B, N, d_model)
        x = self.proj(x).flatten(2).transpose(1, 2)
        # 前置 CLS token
        cls = self.cls_token.expand(B, -1, -1)
        x   = torch.cat([cls, x], dim=1)         # (B, N+1, d_model)
        return x + self.pos_embed

参考解法

class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, d_model=768):
        super().__init__()
        num_patches = (img_size // patch_size) ** 2
        self.proj = nn.Conv2d(in_channels, d_model, kernel_size=patch_size, stride=patch_size)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, d_model))
        self.pos_embed = nn.Parameter(torch.zeros(1, num_patches + 1, d_model))

    def forward(self, x):
        B = x.shape[0]
        x = self.proj(x).flatten(2).transpose(1, 2)
        cls = self.cls_token.expand(B, -1, -1)
        return torch.cat([cls, x], dim=1) + self.pos_embed

面试要点

  • 切块：Conv2d(C, d, kernel=P, stride=P) 是最简洁实现
  • Patch 数：(H/P) * (W/P)
  • CLS token：expand(B,-1,-1)，不用 repeat（节省内存）
  • 序列长度：N + 1（加上 CLS）
