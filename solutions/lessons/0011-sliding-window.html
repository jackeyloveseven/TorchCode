滑动窗口注意力

每个位置只关注距离 ≤ w 的邻居——Mistral 长上下文的秘诀。

学习目标

  • 理解滑动窗口如何将注意力复杂度从 O(S²) 降低
  • 掌握用距离矩阵构造窗口掩码的技巧
  • 理解 window_size 边界情况

核心概念

标准注意力中，每个 token 关注所有 S 个 token（复杂度 O(S²)）。 滑动窗口注意力限制每个位置 i 只能关注满足 |i - j| ≤ window_size 的位置 j。

掩码构造：距离矩阵

S = 5, window_size = 1
idx  = [0, 1, 2, 3, 4]
dist = |idx.unsqueeze(0) - idx.unsqueeze(1)|
# 距离矩阵:
# [[0, 1, 2, 3, 4],
#  [1, 0, 1, 2, 3],
#  [2, 1, 0, 1, 2],
#  [3, 2, 1, 0, 1],
#  [4, 3, 2, 1, 0]]
mask = dist > window_size  # True 的位置填 -inf

PyTorch 实现

def sliding_window_attention(Q, K, V, window_size):
    d_k = K.size(-1)
    scores = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(d_k)  # (B, S, S)
    S = Q.size(1)
    idx  = torch.arange(S, device=Q.device)
    mask = (idx.unsqueeze(0) - idx.unsqueeze(1)).abs() > window_size
    # mask: (S, S)，True = 窗口外，需要 mask 掉
    scores  = scores.masked_fill(mask.unsqueeze(0), float('-inf'))
    weights = torch.softmax(scores, dim=-1)
    return torch.bmm(weights, V)
两个边界情况：
• window_size=0：只关注自己（对角线），输出 = V 的当前行
• window_size >= S-1：等同于标准注意力，无掩码效果

测验

Q1 · 窗口范围

window_size=1，位置 2（从 0 开始）能关注哪些位置？

  • A 只有位置 2 自己
  • B 位置 1、2、3
  • C 位置 0、1、2
  • D 所有位置

Q2 · 距离矩阵

idx.unsqueeze(0) - idx.unsqueeze(1)（idx 长度为 S）的结果 shape？

  • A (S,)（一维）
  • B (1, S)
  • C (S, S)
  • D (2, S)

Q3 · 边界情况

window_size=0 时，输出等价于什么？

  • A 直接返回 V（每个位置只关注自身）
  • B 全零输出
  • C 标准注意力（无掩码）
  • D 报错，window_size 不能为 0

参考解法

def sliding_window_attention(Q, K, V, window_size):
    d_k = K.size(-1)
    scores = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(d_k)
    S   = Q.size(1)
    idx = torch.arange(S, device=Q.device)
    mask = (idx.unsqueeze(0) - idx.unsqueeze(1)).abs() > window_size
    scores  = scores.masked_fill(mask.unsqueeze(0), float('-inf'))
    weights = torch.softmax(scores, dim=-1)
    return torch.bmm(weights, V)

面试要点

  • 掩码：距离矩阵 |i-j| > w 的位置填 -inf
  • 构造：arange(S).unsqueeze(0) - arange(S).unsqueeze(1) 广播得距离矩阵
  • 代表模型：Mistral 7B（window=4096），Longformer
  • 注意：这是 dense 模拟，实际生产用稀疏注意力库才真正降低复杂度
