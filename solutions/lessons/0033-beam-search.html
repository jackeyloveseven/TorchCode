束搜索（Beam Search）

同时维护 beam_width 条候选序列，取累积对数概率最高的。

学习目标

  • 理解 Beam Search 如何在搜索空间中权衡质量与效率
  • 掌握 beam 扩展和剪枝的步骤
  • 能写出完整的 Beam Search 循环

核心概念

算法步骤

# 初始状态：beam = [([BOS], log_prob=0)]
# 每步：
# 1. 对每个 beam，计算下一个 token 的分布
# 2. 每个 beam 扩展出 vocab_size 个候选
# 3. 从所有 beam_width * vocab_size 个候选中
#    保留 log_prob 最高的 beam_width 个
# 重复直到所有 beam 生成 EOS 或达到最大长度

# 关键：用 log_prob（加法），不用概率（乘法）
# 避免连乘导致的数值下溢

与贪心搜索的对比

贪心搜索Beam Search (k=5)
候选数1k 条
最优性局部最优近似全局最优
计算量O(L)O(k*L)
用途实时对话翻译、摘要

PyTorch 实现

def beam_search(model, input_ids, beam_width=5, max_len=50, eos_id=2):
    # 初始化 beams：[(token_ids, log_prob)]
    beams = [(input_ids.clone(), 0.0)]
    completed = []

    for _ in range(max_len):
        candidates = []
        for seq, score in beams:
            if seq[-1].item() == eos_id:
                completed.append((seq, score))
                continue
            # 模型前向：获取下一步 logits
            logits = model(seq.unsqueeze(0))[0, -1]   # (vocab,)
            log_probs = torch.log_softmax(logits, dim=-1)
            # 取 top-beam_width 个候选
            top_probs, top_ids = log_probs.topk(beam_width)
            for lp, tid in zip(top_probs, top_ids):
                new_seq   = torch.cat([seq, tid.unsqueeze(0)])
                new_score = score + lp.item()
                candidates.append((new_seq, new_score))

        if not candidates:
            break
        # 保留得分最高的 beam_width 条
        candidates.sort(key=lambda x: x[1], reverse=True)
        beams = candidates[:beam_width]

    completed += beams
    completed.sort(key=lambda x: x[1] / len(x[0]), reverse=True)  # length normalize
    return completed[0][0]

Beam Search 用 log_prob 累加而不是 prob 相乘，原因是？

  • A 加法比乘法更快
  • B 概率连乘会数值下溢（非常小），log 域加法稳定

  • D 方便计算梯度

参考解法

def beam_search(model, input_ids, beam_width=5, max_len=50, eos_id=2):
    beams = [(input_ids.clone(), 0.0)]
    completed = []
    for _ in range(max_len):
        candidates = []
        for seq, score in beams:
            if seq[-1].item() == eos_id:
                completed.append((seq, score)); continue
            logits = model(seq.unsqueeze(0))[0, -1]
            log_probs = torch.log_softmax(logits, dim=-1)
            top_probs, top_ids = log_probs.topk(beam_width)
            for lp, tid in zip(top_probs, top_ids):
                candidates.append((torch.cat([seq, tid.unsqueeze(0)]),
                                   score + lp.item()))
        if not candidates: break
        beams = sorted(candidates, key=lambda x: x[1], reverse=True)[:beam_width]
    completed += beams
    return max(completed, key=lambda x: x[1] / len(x[0]))[0]

面试要点

  • 算法：维护 k 条序列，每步扩展后剪枝到 k 条
  • log_prob：用加法代替概率乘法，避免数值下溢
  • 长度归一化：score / len(seq)，防止偏向短序列
  • 局限：计算量 O(k*L)，仍可能错过全局最优
