DPO 损失

直接偏好优化：无需奖励模型，用对比对数似然直接优化偏好。

学习目标

  • 理解 DPO 如何绕过 RLHF 的奖励模型
  • 掌握 logsigmoid(β * (chosen_reward - rejected_reward)) 的含义
  • 能手写 DPO 损失函数

核心概念

DPO 的推导思路

# 标准 RLHF：训练奖励模型 → PPO 强化学习优化（复杂）
# DPO 洞察：从 RL 最优解中推导出等价损失（直接优化！）

# 对每对 (chosen, rejected) 数据：
# reward(π, y|x) = β * log(π(y|x)/π_ref(y|x))
#                = β * [logprob_π(y|x) - logprob_ref(y|x)]

# DPO 损失：最大化 chosen 优于 rejected 的对数几率
# L = -logsigmoid(β * (log_ratio_chosen - log_ratio_rejected))
# 其中：log_ratio = logprob_policy - logprob_reference

PyTorch 实现

def dpo_loss(policy_chosen_logps, policy_rejected_logps,
             ref_chosen_logps, ref_rejected_logps, beta=0.1):
    # 所有 logps：(B,) 各自序列的 log-likelihood 之和

    # 计算 log ratio（策略相对参考的对数优势）
    chosen_log_ratio   = policy_chosen_logps   - ref_chosen_logps
    rejected_log_ratio = policy_rejected_logps - ref_rejected_logps

    # DPO 损失（Bradley-Terry 偏好模型）
    logits = beta * (chosen_log_ratio - rejected_log_ratio)
    loss   = -F.logsigmoid(logits).mean()
    return loss
直觉：β 控制 KL 惩罚强度（策略不要偏离参考太远）。 β 越大 → 越保守（接近 ref 模型）；β 越小 → 越激进（更自由优化偏好）。 通常 β=0.1 是好的默认值。

参考解法

def dpo_loss(policy_chosen_logps, policy_rejected_logps,
             ref_chosen_logps, ref_rejected_logps, beta=0.1):
    chosen_log_ratio   = policy_chosen_logps   - ref_chosen_logps
    rejected_log_ratio = policy_rejected_logps - ref_rejected_logps
    return (-F.logsigmoid(beta * (chosen_log_ratio - rejected_log_ratio))).mean()

面试要点

  • 公式：-logsigmoid(β*(chosen_ratio - rejected_ratio))
  • log_ratio：policy_logp - ref_logp（策略相对参考的优势）
  • β：KL 惩罚，控制偏离参考的幅度
  • 数据：每条样本是 (prompt, chosen_response, rejected_response)
