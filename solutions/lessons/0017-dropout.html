Dropout

随机丢弃神经元防过拟合——训练时 mask，推理时恢复。

学习目标

  • 理解 inverted dropout（训练时除以 1-p）的原理
  • 掌握训练/推理不同行为的控制方式
  • 能手写支持 training 标志的 Dropout

核心概念

Inverted Dropout（反向 Dropout）

# 训练时：以概率 p 置零，并除以 (1-p) 缩放
# 这样期望值保持不变：
# E[x_out] = (1-p) * x/(1-p) + p * 0 = x

# 推理时：直接返回 x（不需要任何缩放）
# 因为期望值在训练时已经校正过了

为什么要除以 (1-p)？

# 不除的情况（原始 Dropout 论文）：
# 训练：随机置零（期望 = 0.5x，如果 p=0.5）
# 推理：乘以 0.5（手动补偿）
# → 推理时要记得乘补偿系数，麻烦

# Inverted Dropout（现代实践）：
# 训练：置零 + 除以 (1-p) → 期望 = x
# 推理：直接返回 x
# → 推理代码更干净，不用改

PyTorch 实现

def dropout(x, p=0.5, training=True):
    if not training or p == 0:
        return x
    # 生成 Bernoulli mask：以概率 (1-p) 为 True
    mask = (torch.rand_like(x) > p).float()
    return x * mask / (1 - p)    # inverted dropout
nn.Module 版本：nn.Dropout(p=0.5) 内部与上面等价， 会自动根据 model.train() / model.eval() 切换行为。

测验

Q1 · Inverted Dropout

Inverted Dropout 在训练时为什么要除以 (1-p)？

  • A 增大学习率效果
  • B 让 mask 更稀疏
  • C 保持输出期望值不变，推理时无需额外缩放
  • D 防止梯度爆炸

Q2 · 推理行为

使用 Inverted Dropout，推理时（training=False）的行为是？

  • A 直接返回 x（无 mask，无缩放）
  • B 乘以 (1-p)
  • C 乘以 p
  • D 随机 mask 但不缩放

Q3 · Mask 生成

torch.rand_like(x) > p 生成的 mask 中，True 的期望比例是？

  • A p
  • B 1-p
  • C 0.5（与 p 无关）
  • D 1.0（全部为 True）

参考解法

def dropout(x, p=0.5, training=True):
    if not training or p == 0.0:
        return x
    mask = (torch.rand_like(x) > p).float()
    return x * mask / (1 - p)

面试要点

  • Inverted Dropout：训练时 x * mask / (1-p)
  • 推理时：直接返回 x
  • Mask：rand_like(x) > p，保留概率 = 1-p
  • 常见 p 值：0.1（Transformer），0.5（FC 层）
