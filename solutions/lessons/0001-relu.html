实现 ReLU

PyTorch 最常用的激活函数，也是布尔掩码技巧的第一个练兵场。

学习目标

  • 理解 ReLU 的数学定义与直觉
  • 掌握 布尔掩码这一 PyTorch 核心惯用法
  • 知道为什么 in-place 操作会破坏梯度计算
  • 通过所有测试（数值、形状、梯度、性能）

为什么需要激活函数？

神经网络的核心操作是矩阵乘法（线性变换）。问题在于： 线性变换的复合仍然是线性变换。无论叠多少层，没有激活函数的网络 等价于单层线性模型，无法拟合任何非线性关系。

激活函数在每层之后引入非线性，让网络具备学习复杂模式的能力。

为什么 ReLU 比 Sigmoid / Tanh 更常用？

函数输出范围正区间导数问题
Sigmoid(0, 1)最大 0.25梯度消失：多层相乘后趋近 0
Tanh(-1, 1)最大 1.0同上，虽好些但仍存在
ReLU[0, +∞)恒为 1负区间梯度死亡（可接受）

ReLU 正区间导数恒为 1，梯度可以无衰减地传递到任意深度，这是深度学习实用化的关键原因之一。

数学定义

ReLU(x) = max(0, x)

逐元素操作，等价于：

ReLU(x) = x,  if x > 0
          0,  if x ≤ 0

示例：

Input:  tensor([-2., -1.,  0.,  1.,  2.])
Output: tensor([ 0.,  0.,  0.,  1.,  2.])

梯度（导数）

∂ReLU/∂x = 1,  if x > 0
           0,  if x ≤ 0   (x=0 处通常定义为 0)
直觉：正区间，梯度直接"穿透"；负区间，梯度被"截断"。 这就是 ReLU 解决梯度消失问题的根本原因。

PyTorch 实现：布尔掩码技巧

约束：不能使用 torch.relu、F.relu、torch.clamp 或任何内置激活函数。必须支持 autograd。

核心思路：布尔张量 → 浮点掩码 → 逐元素乘法

在 PyTorch 中，比较操作返回 BoolTensor（True / False）， 调用 .float() 将其转为 1.0 / 0.0：

x = torch.tensor([-2., -1., 0., 1., 2.])

# 步骤 1：比较，得到 BoolTensor
mask = x > 0
# tensor([False, False, False,  True,  True])

# 步骤 2：转为 FloatTensor
mask_f = mask.float()
# tensor([0., 0., 0., 1., 1.])

# 步骤 3：逐元素乘法
result = x * mask_f
# tensor([0., 0., 0., 1., 2.])  ← 就是 ReLU！

一行写完：

def relu(x: torch.Tensor) -> torch.Tensor:
    return x * (x > 0).float()

为什么这支持梯度？

PyTorch 的 autograd 追踪整个计算图。对于 y = x * mask：

  • 正区域（mask = 1.0）：∂y/∂x = 1，梯度原值传过去
  • 负区域（mask = 0.0）：∂y/∂x = 0，梯度被截断

(x > 0) 本身不可微，autograd 将其视为常数（停止梯度追踪）， 这正好符合 ReLU 导数的定义。

x = torch.tensor([-1., 0., 1., 2.], requires_grad=True)
out = x * (x > 0).float()
out.sum().backward()
print(x.grad)
# tensor([0., 0., 1., 1.])  ✓

另一种正确写法（了解即可）

def relu(x: torch.Tensor) -> torch.Tensor:
    return torch.where(x > 0, x, torch.zeros_like(x))

torch.where(condition, a, b) 条件选择，同样支持梯度。 两种写法在竞赛/面试中都可接受，布尔掩码写法更简洁常见。

⚠️ 错误写法：in-place 操作

# ❌ 错误！in-place 修改破坏计算图
def relu_wrong(x):
    x[x < 0] = 0
    return x
规则：PyTorch 的 autograd 需要保存中间值来计算梯度。 in-place 操作（x[...] = ...、x.fill_() 等） 会覆盖这些中间值，导致反向传播报错或结果错误。 实现算子时，永远返回新张量，不要原地修改输入。

参考解法

import torch

def relu(x: torch.Tensor) -> torch.Tensor:
    return x * (x > 0).float()
为什么这是最佳写法？
• 简洁，一行完成
• 不用 if，天然支持任意形状 tensor
• 支持 autograd（无 in-place 操作）
• 在面试白板上写出来，考官会满意

在 Jupyter 运行验证：

from torch_judge import check
check("relu")  # 应该全部通过

面试要点总结

  • 定义：ReLU(x) = max(0, x)，逐元素操作
  • 实现：x * (x > 0).float()
  • 梯度：正区间传 1，负区间传 0；通过乘法自然实现
  • 禁忌：不要 in-place 修改输入张量
  • 延伸：Leaky ReLU = torch.where(x > 0, x, 0.01 * x)；能写出来加分
