第 14 课Hard

KV Cache 注意力

推理加速的核心：缓存历史 K/V，每步只投影新 token。

学习目标

  • 理解自回归推理的计算瓶颈
  • 掌握 KV Cache 的存储和 cat 拼接方式
  • 理解为什么 Q 只用新 token，K/V 用全部历史

核心概念

自回归生成每步生成一个新 token。朴素实现每步都重新计算所有 token 的 K/V，浪费算力。

KV Cache 的思路

# 推理第 t 步：已有 t-1 个 token，新生成第 t 个
# 朴素：重新计算所有 t 个 token 的 K/V
# KV Cache：
#   - K_past, V_past: 缓存了前 t-1 个 token 的 K/V
#   - 只计算第 t 个 token 的 Q/K/V
#   - K_all = cat([K_past, K_new], dim=-2)  # 拼接历史
#   - 用 Q_new 关注 K_all / V_all

Cache 数据结构

Cache 是 tuple (K_past, V_past)，形状各为 (B, h, S_past, d_k)。 首次调用传 None，后续传上一步返回的 cache。

PyTorch 实现

class KVCacheAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, cache=None):
        # x: (B, S_new, D)，S_new=1 in autoregressive decoding
        B, S_new, D = x.shape
        h, dk = self.num_heads, self.d_k

        # 只对新 token 投影 Q/K/V
        q = self.W_q(x).view(B, S_new, h, dk).transpose(1, 2)
        k = self.W_k(x).view(B, S_new, h, dk).transpose(1, 2)
        v = self.W_v(x).view(B, S_new, h, dk).transpose(1, 2)

        # 拼接历史 KV
        if cache is not None:
            k_past, v_past = cache
            k = torch.cat([k_past, k], dim=2)   # (B, h, S_all, dk)
            v = torch.cat([v_past, v], dim=2)

        new_cache = (k, v)  # 更新后的 cache 返回给下一步

        scores  = (q @ k.transpose(-2, -1)) / math.sqrt(dk)
        weights = torch.softmax(scores, dim=-1)
        out = (weights @ v).transpose(1, 2).contiguous().view(B, S_new, D)
        return self.W_o(out), new_cache
效率：无 KV Cache 时每步复杂度 O(S²)；有 KV Cache 时每步 O(S)， 整个生成序列总复杂度 O(S²)→O(S) 每步。

测验

Q1 · Q vs KV

KV Cache 中，为什么 Q 只用新 token，而 K/V 用全部历史？

  • A Q 的计算更耗时，所以省略历史
  • B 历史 Q 已经被上一步使用过了
  • C Q 代表当前预测位置的查询；K/V 提供所有历史上下文
  • D Q 和历史无关，只取决于当前 token

Q2 · cat 维度

k_past: (B, h, t-1, dk)，k_new: (B, h, 1, dk)，沿哪个维度 cat？

  • A dim=0（batch）
  • B dim=2（序列长度维）
  • C dim=1（头数维）
  • D dim=-1（dk 维）

Q3 · KV Cache 的代价

KV Cache 最主要的缺点是什么？

  • A 显存随序列长度线性增长
  • B 每步计算量增加
  • C 不支持批量推理
  • D 需要额外训练才能使用

参考解法

class KVCacheAttention(nn.Module):
    def forward(self, x, cache=None):
        B, S_new, D = x.shape
        h, dk = self.num_heads, self.d_k
        q = self.W_q(x).view(B, S_new, h, dk).transpose(1, 2)
        k = self.W_k(x).view(B, S_new, h, dk).transpose(1, 2)
        v = self.W_v(x).view(B, S_new, h, dk).transpose(1, 2)
        if cache is not None:
            k = torch.cat([cache[0], k], dim=2)
            v = torch.cat([cache[1], v], dim=2)
        scores  = (q @ k.transpose(-2,-1)) / math.sqrt(dk)
        weights = torch.softmax(scores, dim=-1)
        out = (weights @ v).transpose(1,2).contiguous().view(B, S_new, D)
        return self.W_o(out), (k, v)

面试要点

  • 思路：缓存历史 K/V，每步只投影新 token
  • 拼接：torch.cat([k_past, k_new], dim=2)
  • 返回：(output, new_cache)，cache 传给下一步
  • 代价：显存随序列长度线性增长（GQA/MQA 可减小）
