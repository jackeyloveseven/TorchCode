实现 BatchNorm

训练用批统计量，推理用滑动统计量——两种模式必须分开处理。

学习目标

  • 理解训练模式和推理模式的差异
  • 掌握滑动均值/方差的 in-place 更新方式
  • 理解 BatchNorm 在 dim=0（批次维）归一化

核心概念

BN(x) = γ · (x − μ_B) / √(σ_B² + ε) + β

训练 vs 推理

训练推理
均值/方差来源当前 batch（dim=0）滑动均值/方差
更新 running stats是（momentum 加权）否
归一化后数值更稳定行为确定性

滑动统计量更新

# momentum=0.1 默认值（PyTorch 约定）
running_mean = (1 - momentum) * running_mean + momentum * batch_mean
running_var  = (1 - momentum) * running_var  + momentum * batch_var

注意这是 in-place 更新（running_mean 是传入的张量，直接修改它的值）。

PyTorch 实现

def my_batch_norm(x, gamma, beta, running_mean, running_var,
                  eps=1e-5, momentum=0.1, training=True):
    if training:
        batch_mean = x.mean(dim=0)                    # (C,)
        batch_var  = x.var(dim=0, unbiased=False)     # (C,)
        # in-place 更新滑动统计量
        running_mean.mul_(1 - momentum).add_(momentum * batch_mean.detach())
        running_var.mul_(1 - momentum).add_(momentum * batch_var.detach())
        mean, var = batch_mean, batch_var
    else:
        mean, var = running_mean, running_var

    x_norm = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_norm + beta
关键：更新 running stats 时需要 .detach()， 防止把 running_mean/var 引入计算图（它们不需要梯度）。

测验

Q1 · 归一化维度

输入 (B, C)，BatchNorm 在哪个维度计算均值和方差？

  • A dim=0（B，每通道跨样本统计）
  • B dim=1（C，每样本跨通道统计）
  • C dim=-1（最后维度）
  • D 所有维度

Q2 · 推理模式

推理（training=False）时为什么不用当前 batch 的统计量？

  • A 推理时 batch_size=1，方差为 0
  • B 推理时 batch 可能很小甚至为 1，统计量不稳定；需要确定性结果
  • C 推理时不允许计算梯度
  • D running stats 比 batch stats 更精确

Q3 · momentum 语义

momentum=0.1 更新公式是？

  • A running = 0.1 * old + 0.9 * batch
  • B running = old + 0.1 * (batch - old)
  • C running = 0.9 * old + 0.1 * batch
  • D running = 0.1 * batch（直接替换）

参考解法

def my_batch_norm(x, gamma, beta, running_mean, running_var,
                  eps=1e-5, momentum=0.1, training=True):
    if training:
        batch_mean = x.mean(dim=0)
        batch_var  = x.var(dim=0, unbiased=False)
        running_mean.mul_(1 - momentum).add_(momentum * batch_mean.detach())
        running_var.mul_(1 - momentum).add_(momentum * batch_var.detach())
        mean, var = batch_mean, batch_var
    else:
        mean, var = running_mean, running_var
    x_norm = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_norm + beta

面试要点

  • 训练：用 batch mean/var，in-place 更新 running stats
  • 推理：用 running mean/var，不更新
  • detach()：更新 running stats 时避免引入计算图
  • vs LayerNorm：BatchNorm 归一化 dim=0，LayerNorm 归一化 dim=-1
