OPD 损失（加权反向 KL）

Optimal Policy Distillation：用反向 KL + 质量权重，蒸馏优质大模型。

学习目标

  • 理解 OPD 的问题背景：策略蒸馏
  • 掌握反向 KL 散度 KL(student||teacher) 的实现
  • 理解质量权重 w(y) 的作用

核心概念

OPD 的思路

# 目标：蒸馏一个优秀大模型（teacher）到小模型（student）
# 普通 SFT：直接最大化 teacher 的输出似然
# 问题：teacher 的次优回答也被学习

# OPD 洞察：加权反向 KL，质量高的样本权重大
# L_OPD = E_{y~p_teacher}[w(y) * KL(student || teacher)]
# 其中 w(y) = r(y) / Z（奖励归一化权重）

反向 KL vs 正向 KL

正向 KL(teacher||student)反向 KL(student||teacher)
优化方向student 覆盖 teacher 所有模式student 专注于 teacher 的主要模式
行为mean-seeking（扩散）mode-seeking（聚焦）
用途普通蒸馏偏好对齐蒸馏

PyTorch 实现

def opd_loss(student_logps, teacher_logps, rewards, beta=0.1):
    # student_logps, teacher_logps: (B,) 序列的 log-likelihood
    # rewards: (B,) 奖励分数

    # 质量权重（softmax over rewards）
    weights = torch.softmax(rewards / beta, dim=0)   # (B,)

    # 反向 KL(student || teacher) = student_logp - teacher_logp
    # E_student[log π_student / π_teacher]
    # 在样本级别近似：
    kl_per_sample = student_logps - teacher_logps    # log ratio

    # 加权平均
    loss = (weights * kl_per_sample).sum()
    return loss
与 DPO 的联系：OPD 可以看作 DPO 的连续版本： DPO 用 binary 偏好（chosen/rejected），OPD 用连续奖励分数作为权重， 更细粒度地区分不同质量的样本。

测验

Q1 · 反向 KL 特性

KL(student||teacher) 的"mode-seeking"意味着？

  • A student 尽量覆盖 teacher 的所有模式
  • B student 专注于 teacher 概率高的区域，忽略低概率区域
  • C student 和 teacher 完全相同
  • D student 避开 teacher 的主要模式

Q2 · 质量权重

OPD 中 weights = softmax(rewards/β) 的作用是？

  • A 归一化 loss 防止数值问题
  • B 随机选择训练样本
  • C 让高奖励样本贡献更大梯度，聚焦优质样本学习
  • D 替代 KL 散度的计算

Q3 · OPD vs DPO

OPD 和 DPO 的最主要区别是？

  • A OPD 用连续奖励权重，DPO 用 binary 偏好（chosen/rejected）
  • B OPD 不需要参考模型，DPO 需要
  • C OPD 用于训练，DPO 用于推理
  • D 两者完全等价，只是名称不同

参考解法

def opd_loss(student_logps, teacher_logps, rewards, beta=0.1):
    weights = torch.softmax(rewards / beta, dim=0)
    kl_per_sample = student_logps - teacher_logps
    return (weights * kl_per_sample).sum()

面试要点

  • 反向 KL：student_logp - teacher_logp（mode-seeking）
  • 质量权重：softmax(r/β)，聚焦高奖励样本
  • vs DPO：连续奖励 vs binary 偏好
  • β：温度参数，控制权重集中程度
