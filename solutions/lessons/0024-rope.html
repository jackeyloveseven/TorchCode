旋转位置编码 (RoPE)

LLaMA 的位置编码：把位置信息编成旋转矩阵，通过配对维度旋转角度实现。

学习目标

  • 理解 RoPE 的核心思想：旋转向量对
  • 掌握频率矩阵的构造和应用
  • 能写出 apply_rope(x, position_ids)

核心概念

为什么旋转？

RoPE 希望 内积只依赖相对位置：q_m · k_n = f(m-n)。 旋转矩阵满足：rotate(q, m) · rotate(k, n) = q · rotate(k, n-m)， 内积天然包含相对位置信息。

旋转操作

# 将 d_k 维向量按对拆分，每对 (x_{2i}, x_{2i+1}) 旋转角度 θ_i * pos
# θ_i = 1 / (10000^(2i/d))   — 频率，i 越大频率越低

# 旋转公式（复数乘法）：
# [x_r, x_i] * [cos(θ*m), sin(θ*m)] =
#   [x_r*cos - x_i*sin, x_r*sin + x_i*cos]

# 等价于：
# rotate_half(x): 将后半维移到前半，并取负
# x * cos + rotate_half(x) * sin

PyTorch 实现

def precompute_rope_freqs(d_k, max_seq_len, base=10000):
    # 频率：(d_k/2,)
    i   = torch.arange(0, d_k, 2).float()
    inv_freq = 1.0 / (base ** (i / d_k))
    # 位置 × 频率 → (max_seq_len, d_k/2)
    t   = torch.arange(max_seq_len).float()
    freqs = torch.outer(t, inv_freq)
    # cos/sin 各 (max_seq_len, d_k/2)
    return torch.cos(freqs), torch.sin(freqs)

def rotate_half(x):
    x1 = x[..., :x.shape[-1]//2]   # 前半
    x2 = x[..., x.shape[-1]//2:]   # 后半
    return torch.cat([-x2, x1], dim=-1)

def apply_rope(x, cos, sin):
    # x: (B, h, S, d_k), cos/sin: (S, d_k/2)
    cos = cos.unsqueeze(0).unsqueeze(0)   # (1,1,S,dk/2) → repeat
    sin = sin.unsqueeze(0).unsqueeze(0)
    cos = cos.repeat(1, 1, 1, 2)          # (1,1,S,dk)
    sin = sin.repeat(1, 1, 1, 2)
    return x * cos + rotate_half(x) * sin
LLaMA 细节：RoPE 只应用到 Q 和 K，不应用到 V。 位置信息已经通过 Q·K 的内积传入注意力权重，V 不需要。

面试要点

  • 核心：按位置旋转 Q/K，内积只依赖相对位置
  • 旋转：x*cos + rotate_half(x)*sin
  • 频率：1/(10000^(2i/d))，低维高频、高维低频
  • 代表模型：LLaMA 1/2/3, Qwen, Mistral
