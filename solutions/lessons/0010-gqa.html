第 10 课Hard

分组查询注意力 (GQA)

LLaMA 2 / Mistral 用的技术：KV 头少于 Q 头，大幅减小 KV 缓存。

学习目标

  • 理解 GQA 如何用少量 KV 头服务多个 Q 头
  • 掌握 repeat_interleave 扩展 KV 头的技巧
  • 理解 GQA 对 KV Cache 大小的影响

核心概念

MHAMQAGQA
Q 头数hhh
KV 头数h1g（1 < g < h）
每组 Q 头数1hh/g

GQA 是 MHA（每头有自己的 KV）和 MQA（所有头共享一个 KV）之间的折中。 LLaMA 2-70B 用 8 个 KV 头配 64 个 Q 头（每组 8 个 Q 头共享 1 个 KV 头）。

关键操作：KV 头扩展

# KV 投影: (B, S, num_kv_heads * d_k)
k = self.W_k(x).view(B, S, num_kv_heads, d_k).transpose(1, 2)  # (B, g, S, dk)
# 每个 KV 头要服务 groups_per_head = h // g 个 Q 头
groups = num_heads // num_kv_heads
k = k.repeat_interleave(groups, dim=1)   # (B, h, S, dk)

PyTorch 实现

class GroupQueryAttention:
    def __init__(self, d_model, num_heads, num_kv_heads):
        self.num_heads    = num_heads
        self.num_kv_heads = num_kv_heads
        self.d_k   = d_model // num_heads
        self.W_q   = nn.Linear(d_model, d_model)
        self.W_k   = nn.Linear(d_model, num_kv_heads * self.d_k)
        self.W_v   = nn.Linear(d_model, num_kv_heads * self.d_k)
        self.W_o   = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, S, D = x.shape
        h, g, dk = self.num_heads, self.num_kv_heads, self.d_k
        groups = h // g

        q = self.W_q(x).view(B, S, h, dk).transpose(1, 2)   # (B, h, S, dk)
        k = self.W_k(x).view(B, S, g, dk).transpose(1, 2)   # (B, g, S, dk)
        v = self.W_v(x).view(B, S, g, dk).transpose(1, 2)

        k = k.repeat_interleave(groups, dim=1)  # (B, h, S, dk)
        v = v.repeat_interleave(groups, dim=1)

        scores  = (q @ k.transpose(-2, -1)) / math.sqrt(dk)
        weights = torch.softmax(scores, dim=-1)
        out = (weights @ v).transpose(1, 2).contiguous().view(B, S, D)
        return self.W_o(out)

测验

Q1 · 参数形状

num_heads=8, num_kv_heads=2, d_model=256 时，W_k 的输出维度是？

  • A 256（和 W_q 一样）
  • B 32（只有一个 KV 头的维度）
  • C 64（num_kv_heads * d_k = 2 * 32）
  • D 128（一半的 d_model）

Q2 · KV 扩展

k: (B, 2, S, dk)，k.repeat_interleave(4, dim=1) 的结果 shape？

  • A (B, 2, S, 4*dk)
  • B (B, 8, S, dk)
  • C (4*B, 2, S, dk)
  • D (B, 2, 4*S, dk)

Q3 · GQA 的收益

相比 MHA，GQA 主要节省了什么？

  • A KV Cache 显存（推理时）
  • B Q 投影的参数量
  • C 训练时的梯度显存
  • D Softmax 的计算量

参考解法

class GroupQueryAttention:
    def __init__(self, d_model, num_heads, num_kv_heads):
        self.num_heads    = num_heads
        self.num_kv_heads = num_kv_heads
        self.d_k = d_model // num_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, num_kv_heads * self.d_k)
        self.W_v = nn.Linear(d_model, num_kv_heads * self.d_k)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, S, D = x.shape
        h, g, dk = self.num_heads, self.num_kv_heads, self.d_k
        groups = h // g
        q = self.W_q(x).view(B, S, h, dk).transpose(1, 2)
        k = self.W_k(x).view(B, S, g, dk).transpose(1, 2).repeat_interleave(groups, dim=1)
        v = self.W_v(x).view(B, S, g, dk).transpose(1, 2).repeat_interleave(groups, dim=1)
        scores  = (q @ k.transpose(-2, -1)) / math.sqrt(dk)
        weights = torch.softmax(scores, dim=-1)
        out = (weights @ v).transpose(1, 2).contiguous().view(B, S, D)
        return self.W_o(out)

面试要点

  • 核心思路：g 个 KV 头，每个服务 h/g 个 Q 头
  • 扩展技巧：repeat_interleave(groups, dim=1)
  • 收益：KV Cache 缩小为 g/h 倍（节省推理显存）
  • 代表模型：LLaMA 2-70B（g=8, h=64），Mistral 7B（g=8, h=32）
