GPT-2 Transformer 块

综合题：Pre-Norm 架构 + 因果注意力 + FFN + 残差连接。

学习目标

  • 掌握 Pre-Norm（先 LN 后注意力/FFN）的架构
  • 理解残差连接 x = x + sublayer(ln(x))
  • 能从零搭出完整的 Transformer 块（继承 nn.Module）

核心概念：Pre-Norm 架构

# GPT-2 Block（Pre-Norm）
x = x + causal_self_attention(ln1(x))   # 残差 + 注意力
x = x + mlp(ln2(x))                     # 残差 + FFN

Pre-Norm vs Post-Norm

Post-Norm（原始 Transformer）Pre-Norm（GPT-2/LLaMA）
顺序x = LN(x + sublayer(x))x = x + sublayer(LN(x))
训练稳定性较差，需要 warmup更稳定，可更大 lr
主流否是（GPT-2, LLaMA, PaLM）

FFN（前馈网络）结构

# GPT-2 风格 FFN（4倍扩展，GELU 激活）
FFN(x) = W_2 * GELU(W_1 * x)
# W_1: (d_model, 4*d_model)，W_2: (4*d_model, d_model)

PyTorch 实现

import math, torch, torch.nn as nn, torch.nn.functional as F

class GPT2Block(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.d_k = d_model // num_heads

        self.ln1 = nn.LayerNorm(d_model)
        self.ln2 = nn.LayerNorm(d_model)

        # 因果自注意力投影
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

        # FFN
        self.fc1 = nn.Linear(d_model, 4 * d_model)
        self.fc2 = nn.Linear(4 * d_model, d_model)

    def _causal_attn(self, x):
        B, S, D = x.shape
        h, dk = self.num_heads, self.d_k
        q = self.W_q(x).view(B,S,h,dk).transpose(1,2)
        k = self.W_k(x).view(B,S,h,dk).transpose(1,2)
        v = self.W_v(x).view(B,S,h,dk).transpose(1,2)
        scores = (q @ k.transpose(-2,-1)) / math.sqrt(dk)
        mask = torch.triu(torch.ones(S,S,device=x.device,dtype=torch.bool), diagonal=1)
        scores = scores.masked_fill(mask, float('-inf'))
        out = (torch.softmax(scores,dim=-1) @ v).transpose(1,2).contiguous().view(B,S,D)
        return self.W_o(out)

    def forward(self, x):
        x = x + self._causal_attn(self.ln1(x))   # 残差 + 注意力
        x = x + self.fc2(F.gelu(self.fc1(self.ln2(x))))  # 残差 + FFN
        return x

参考解法

class GPT2Block(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.ln1 = nn.LayerNorm(d_model)
        self.ln2 = nn.LayerNorm(d_model)
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
        self.fc1 = nn.Linear(d_model, 4 * d_model)
        self.fc2 = nn.Linear(4 * d_model, d_model)

    def forward(self, x):
        B, S, D = x.shape
        h, dk = self.num_heads, self.d_k
        # 因果注意力
        def attn(z):
            q = self.W_q(z).view(B,S,h,dk).transpose(1,2)
            k = self.W_k(z).view(B,S,h,dk).transpose(1,2)
            v = self.W_v(z).view(B,S,h,dk).transpose(1,2)
            sc = (q @ k.transpose(-2,-1)) / math.sqrt(dk)
            mask = torch.triu(torch.ones(S,S,device=x.device,dtype=torch.bool),diagonal=1)
            sc = sc.masked_fill(mask, float('-inf'))
            return self.W_o((torch.softmax(sc,dim=-1)@v).transpose(1,2).contiguous().view(B,S,D))
        x = x + attn(self.ln1(x))
        x = x + self.fc2(F.gelu(self.fc1(self.ln2(x))))
        return x

面试要点

  • 架构：Pre-Norm → 因果多头注意力 → 残差；Pre-Norm → FFN → 残差
  • FFN：4× 扩展 + GELU 激活（GPT-2 用 GELU，LLaMA 用 SwiGLU）
  • 需继承 nn.Module：才能用 .parameters() 和 optimizer
