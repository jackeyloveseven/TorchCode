余弦学习率调度

线性 warmup + 余弦衰减：LLM 训练的标准 LR 策略。

学习目标

  • 理解 warmup 阶段的作用
  • 掌握余弦衰减公式：0.5 * (1 + cos(π * t/T))
  • 能实现 get_lr(step) 函数

核心概念

两阶段调度

# 阶段 1：线性 warmup（step 0 到 warmup_steps）
lr = max_lr * (step / warmup_steps)
# 从 0 线性增到 max_lr

# 阶段 2：余弦衰减（step > warmup_steps）
progress = (step - warmup_steps) / (total_steps - warmup_steps)
lr = min_lr + 0.5 * (max_lr - min_lr) * (1 + cos(π * progress))
# 从 max_lr 余弦衰减到 min_lr

为什么要 warmup？

训练初期模型权重随机，梯度变化大。大 lr 容易导致参数发散。 warmup 让模型先"稳定下来"，再用大 lr 加速收敛。

余弦 vs 线性衰减

余弦衰减前期下降慢，末期下降快（探索充分再精细收敛）；线性衰减匀速下降。 实践中余弦衰减通常更优。

PyTorch 实现

import math

def get_cosine_lr(step, max_lr, min_lr, warmup_steps, total_steps):
    if step < warmup_steps:
        return max_lr * step / warmup_steps
    if step >= total_steps:
        return min_lr
    progress = (step - warmup_steps) / (total_steps - warmup_steps)
    return min_lr + 0.5 * (max_lr - min_lr) * (1 + math.cos(math.pi * progress))
典型配置（LLaMA）： warmup_steps ≈ 2000，min_lr = max_lr * 0.1， total_steps 与训练 token 数量对应（约 1T tokens）。

面试要点

  • Warmup：线性从 0 → max_lr，max_lr * step / warmup_steps
  • 衰减：min_lr + 0.5*(max-min)*(1+cos(π*progress))
  • progress：(step - warmup) / (total - warmup)
  • 典型配置：warmup=2000 steps，min_lr = 0.1 * max_lr
