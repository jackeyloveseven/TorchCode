SwiGLU MLP

LLaMA 的 FFN：门控机制让激活更精确，SiLU 代替 GELU。

学习目标

  • 理解 Gated Linear Unit (GLU) 的门控思想
  • 掌握 SwiGLU：silu(gate) * up 的双投影结构
  • 能写出三投影 SwiGLU FFN

核心概念

从 GELU FFN 到 SwiGLU

# GPT-2 风格：单投影 + GELU
out = W2(GELU(W1(x)))

# SwiGLU：双投影，gate 控制 up 的通过量
gate = W_gate(x)    # (B, S, 4D)
up   = W_up(x)      # (B, S, 4D)
out  = W_down(silu(gate) * up)   # 元素乘

SiLU 激活

silu(x) = x * sigmoid(x)
# 平滑版 ReLU，负值有微弱梯度
# silu(2) ≈ 1.76，silu(-1) ≈ -0.27
门控的直觉：gate 的 silu 输出决定每个维度"打开多少"， up 提供信息量。两者逐元素相乘 = 软性特征选择。

PyTorch 实现

class SwiGLUMLP(nn.Module):
    def __init__(self, d_model, hidden_dim=None):
        super().__init__()
        if hidden_dim is None:
            hidden_dim = 4 * d_model
        self.gate_proj = nn.Linear(d_model, hidden_dim, bias=False)
        self.up_proj   = nn.Linear(d_model, hidden_dim, bias=False)
        self.down_proj = nn.Linear(hidden_dim, d_model, bias=False)

    def forward(self, x):
        gate = self.gate_proj(x)              # (B, S, H)
        up   = self.up_proj(x)               # (B, S, H)
        return self.down_proj(F.silu(gate) * up)
LLaMA 细节：LLaMA 2/3 中 hidden_dim 通常是 2/3 * 4 * d_model 取整到 256 的倍数， 保持参数量与 GPT-2 FFN 相当。

  • B x * torch.sigmoid(x)

Q3 · 门控直觉

SwiGLU 中 gate 的作用最接近哪个比喻？

  • A 软性特征选择器（决定哪些维度被激活）
  • B 归一化层（控制数值大小）
  • C 位置编码（控制序列顺序）
  • D 注意力权重（控制 token 关注范围）

参考解法

class SwiGLUMLP(nn.Module):
    def __init__(self, d_model, hidden_dim=None):
        super().__init__()
        if hidden_dim is None:
            hidden_dim = 4 * d_model
        self.gate_proj = nn.Linear(d_model, hidden_dim, bias=False)
        self.up_proj   = nn.Linear(d_model, hidden_dim, bias=False)
        self.down_proj = nn.Linear(hidden_dim, d_model, bias=False)

    def forward(self, x):
        return self.down_proj(F.silu(self.gate_proj(x)) * self.up_proj(x))

面试要点

  • 公式：down_proj(silu(gate_proj(x)) * up_proj(x))
  • 三个投影：gate, up, down（LLaMA 无 bias）
  • SiLU：x * sigmoid(x)，平滑 ReLU
  • 代表模型：LLaMA 1/2/3, Mistral, Qwen
