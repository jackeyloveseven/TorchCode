第 09 课Hard

因果自注意力

GPT 的核心：上三角掩码 + masked_fill(-inf)，禁止"看未来"。

学习目标

  • 理解因果掩码（causal mask）的含义和构造方式
  • 掌握 torch.triu 和 masked_fill 的用法
  • 理解为什么用 -inf 而不是 0 来掩码

核心概念

自回归语言模型（GPT 风格）在预测第 i 个 token 时，只能看到位置 0 到 i-1 的 token， 不能"偷看"未来。因果注意力通过掩码实现这一约束：

scores[i, j] = QK^T / sqrt(d_k),  if j <= i  (能看到)
scores[i, j] = -inf,               if j > i   (不能看)

softmax 后 exp(-inf) = 0，所以未来位置的注意力权重为 0。

上三角掩码的构造

S = 4  # 序列长度
mask = torch.triu(torch.ones(S, S, dtype=torch.bool), diagonal=1)
# tensor([[False,  True,  True,  True],   ← 第 0 行只能看自己
#         [False, False,  True,  True],   ← 第 1 行能看 0,1
#         [False, False, False,  True],
#         [False, False, False, False]])

diagonal=1：从主对角线上方 1 格开始为 True（即未来位置）。

PyTorch 实现

import math, torch

def causal_attention(Q, K, V):
    d_k = K.size(-1)
    scores = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(d_k)  # (B, S, S)
    S = scores.size(-1)
    mask = torch.triu(
        torch.ones(S, S, device=scores.device, dtype=torch.bool),
        diagonal=1
    )
    scores = scores.masked_fill(mask.unsqueeze(0), float('-inf'))
    weights = torch.softmax(scores, dim=-1)
    return torch.bmm(weights, V)
为什么是 -inf 而不是 0？
直接把分数设为 0 不对：softmax 中 exp(0) = 1，仍会有权重。 设为 -inf 后 exp(-inf) = 0，权重精确为 0。
注意：mask.unsqueeze(0) 把 (S,S) 扩展为 (1,S,S)， 从而广播到 (B,S,S)。

测验

Q1 · triu diagonal

torch.triu(ones(S,S), diagonal=1) 中哪些位置为 True？

  • A j >= i 的位置（包含主对角线）
  • B j > i 的位置（不含主对角线）
  • C j < i 的位置（下三角）
  • D i == j 的位置（仅主对角线）

Q2 · 为什么用 -inf

因果掩码为什么要填 -inf 而不是 0？

  • A -inf 更节省内存
  • B 0 会导致梯度消失
  • C exp(0)=1 仍有权重；exp(-inf)=0 精确屏蔽
  • D PyTorch 的 masked_fill 只支持 -inf

Q3 · 广播

scores: (B, S, S)，mask (S, S)，为什么需要 mask.unsqueeze(0)？

  • A 把 (S,S) 扩展为 (1,S,S)，广播到 (B,S,S)
  • B 转换数据类型
  • C 复制 B 份 mask
  • D masked_fill 不支持 2D mask

参考解法

def causal_attention(Q, K, V):
    d_k = K.size(-1)
    scores = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(d_k)
    S = scores.size(-1)
    mask = torch.triu(torch.ones(S, S, device=scores.device, dtype=torch.bool), diagonal=1)
    scores = scores.masked_fill(mask.unsqueeze(0), float('-inf'))
    weights = torch.softmax(scores, dim=-1)
    return torch.bmm(weights, V)

面试要点

  • 掩码：torch.triu(..., diagonal=1) 构造上三角 bool mask
  • 填充：masked_fill(mask, float('-inf'))，不是 0
  • 广播：mask (S,S) → unsqueeze(0) → (1,S,S)
  • 延伸：滑动窗口注意力 = 在上三角掩码基础上再加距离限制
