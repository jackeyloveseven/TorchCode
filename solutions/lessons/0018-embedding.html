第 18 课Easy

嵌入层

词表到向量：最简单的查表操作，但细节不少。

学习目标

  • 理解 Embedding 本质是带梯度的查找表
  • 掌握用 nn.Parameter 手动实现
  • 理解权重绑定（weight tying）优化

核心概念

Embedding = 查表

# 词表大小 V，嵌入维度 D
# weight: (V, D) 的参数矩阵
# indices: (B, S) 的整数 token id

# 输出 = weight[indices]
# 即：取出每个 token id 对应的行
# 形状：(B, S, D)

权重绑定（Weight Tying）

GPT-2 等模型让输入 Embedding 和输出 Linear 的权重相同：

# embedding.weight: (V, D)
# 输出 logits = hidden @ embedding.weight.T
# 好处：减少参数量（节省 V*D 个参数），效果通常更好

PyTorch 实现

class Embedding(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.weight = nn.Parameter(
            torch.randn(vocab_size, embedding_dim)
        )

    def forward(self, indices):
        # indices: (B, S) integer tensor
        return self.weight[indices]    # (B, S, D)
梯度只流向被选中的行：反向传播时，只有 indices 中出现过的 token id 对应的行会得到梯度更新。 这正是 Embedding 高效的原因——稀疏更新。

  • A 全部 vocab_size 行
  • B 随机一半的行
  • C 当前 batch 中出现过的 token id 对应的行
  • D 梯度最大的 top-k 行

Q3 · 权重绑定

"Weight Tying" 在语言模型中指什么？

  • A 输入 Embedding 权重和输出 Linear 权重共享

  • C Q 和 K 的投影矩阵共享
  • D 奇数层和偶数层权重共享

参考解法

class Embedding(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(vocab_size, embedding_dim))

        return self.weight[indices]

面试要点

  • 本质：查找表，weight[indices]
  • 权重形状：(vocab_size, embedding_dim)
  • 梯度：稀疏，只更新出现过的 token
  • Weight Tying：GPT-2 的输入 Embedding = 输出 Linear.T
