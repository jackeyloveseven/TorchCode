权重初始化

Kaiming / He init：ReLU 激活的正确初始化，std = √(2/fan_in)。

学习目标

  • 理解为什么初始化方式影响训练
  • 掌握 Kaiming（He）初始化的公式
  • 能手写 kaiming_init(weight, activation)

核心概念

信号方差的传播

# 设 y = W @ x，W 有 fan_in 列
# Var(y_i) = Σ_j Var(W_ij) * Var(x_j)
#           = fan_in * Var(w) * Var(x)
# 要保持 Var(y) = Var(x)：
# Var(w) = 1 / fan_in   → Xavier init

ReLU 减半方差 → Kaiming

# ReLU 将约一半输出置零，方差减半
# 所以需要补偿：
# Var(w) = 2 / fan_in   → Kaiming init
# std  = sqrt(2 / fan_in)

# 对应 PyTorch：
torch.nn.init.kaiming_normal_(weight, mode='fan_in', nonlinearity='relu')

Xavier（Glorot）vs Kaiming

XavierKaiming（He）
std√(1/fan_in)√(2/fan_in)
激活tanh、sigmoidReLU、Leaky ReLU
考虑激活非线性否是（增益因子）

PyTorch 实现

def kaiming_init(weight, activation='relu'):
    fan_in = weight.size(1)   # 输入维度
    gain = math.sqrt(2) if activation == 'relu' else 1.0
    std  = gain / math.sqrt(fan_in)
    with torch.no_grad():
        weight.normal_(0, std)
    return weight
增益（gain）：不同激活有不同 gain 值： relu=√2，tanh≈5/3，sigmoid≈1，linear=1。 PyTorch 的 nn.init.calculate_gain() 可自动查表。

参考解法

def kaiming_init(weight, activation='relu'):
    fan_in = weight.size(1)
    gain = math.sqrt(2.0) if activation == 'relu' else 1.0
    std  = gain / math.sqrt(fan_in)
    with torch.no_grad():
        weight.normal_(0, std)
    return weight

面试要点

  • Kaiming std：sqrt(2/fan_in)（ReLU）
  • 为什么 ×2：ReLU 将约一半输出置零，方差减半，需补偿
  • PyTorch 内置：nn.init.kaiming_normal_(w, mode='fan_in')
  • with no_grad：原地修改参数时需要 torch.no_grad()
