INT8 量化

per-row 缩放因子，round + clamp 到 [-128, 127]，显存减半。

学习目标

  • 理解线性量化的缩放公式
  • 掌握 per-row（per-tensor）量化的实现
  • 理解反量化（dequantize）还原原始值

核心概念

线性量化

# 量化：float32 → int8
# scale = max(abs(row)) / 127      # 每行单独缩放
# q = round(x / scale).clamp(-128, 127).to(int8)

# 反量化：int8 → float32
# x_approx = q.float() * scale

# 误差来源：round 四舍五入的量化误差

Per-tensor vs Per-row vs Per-channel

粒度scale 数量精度用途
Per-tensor1最低激活量化
Per-row行数中等权重量化（常见）
Per-channel通道数最高卷积权重

PyTorch 实现

def quantize_int8(x):
    # x: (N, D) float32
    scale = x.abs().max(dim=-1, keepdim=True).values / 127.0
    scale = scale.clamp(min=1e-8)   # 避免除零
    q = (x / scale).round().clamp(-128, 127).to(torch.int8)
    return q, scale

def dequantize_int8(q, scale):
    # q: (N, D) int8, scale: (N, 1) float32
    return q.float() * scale

# 演示：量化误差很小
x = torch.randn(4, 8)
q, scale = quantize_int8(x)
x_hat = dequantize_int8(q, scale)
print(f"最大误差: {(x - x_hat).abs().max():.4f}")
实际应用：bitsandbytes 库的 8-bit Adam 和 LLM.int8() 就是基于这个原理。 权重量化为 INT8，计算时反量化（或混合精度计算），推理速度 ≈ 2x，精度损失很小。

测验

Q1 · Scale 计算

per-row INT8 量化的 scale 是如何计算的？

  • A 行均值
  • B 行标准差
  • C 行最大绝对值 / 127
  • D 固定常数 0.01

Q2 · 显存节省

FP32 量化为 INT8，权重显存降低多少倍？

  • A 2x（FP16 已做了 2x）
  • B 约 4x（4 字节 → 1 字节）
  • C 8x
  • D 无节省（scale 也要存储）

Q3 · 反量化

从 INT8 还原 float32 的操作是？

  • A q.float() * scale
  • B q / scale
  • C q + scale
  • D sigmoid(q * scale)

参考解法

def quantize_int8(x):
    scale = x.abs().max(dim=-1, keepdim=True).values / 127.0
    scale = scale.clamp(min=1e-8)
    q = (x / scale).round().clamp(-128, 127).to(torch.int8)
    return q, scale

def dequantize_int8(q, scale):
    return q.float() * scale

面试要点

  • 量化公式：round(x/scale).clamp(-128,127)
  • scale：max_abs / 127，per-row 保证精度
  • 反量化：q.float() * scale
  • 显存：FP32→INT8 约 4x，FP16→INT8 约 2x
