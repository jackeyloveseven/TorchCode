LoRA 低秩适配

冻结预训练权重，只训练低秩矩阵 A 和 B，用 α/r 控制缩放。

学习目标

  • 理解 LoRA 的低秩近似思想
  • 掌握 B@A 初始化（B=0，A=randn）
  • 理解 α/r 缩放因子的作用

核心概念

LoRA 公式

# 预训练权重：W ∈ R^(out × in)，冻结
# LoRA 增量：ΔW = B @ A，其中
#   A: (r, in)，初始化为标准正态
#   B: (out, r)，初始化为全零
#   r ≪ min(in, out)（秩，通常 4~64）

# 前向传播：
y = (W + α/r * B @ A) @ x
# W@x 是冻结的基础输出，B@A@x 是可训练的 delta

为什么 B 初始化为 0？

初始时 ΔW = B@A = 0，模型行为与原始预训练模型完全一致， 微调从稳定的起点开始，而不是随机扰动。

PyTorch 实现

class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, r=4, alpha=16):
        super().__init__()
        self.r     = r
        self.alpha = alpha
        self.scaling = alpha / r

        # 冻结的预训练权重
        self.weight = nn.Parameter(
            torch.randn(out_features, in_features), requires_grad=False
        )
        # 可训练的低秩矩阵
        self.lora_A = nn.Parameter(torch.randn(r, in_features) * 0.02)
        self.lora_B = nn.Parameter(torch.zeros(out_features, r))

    def forward(self, x):
        base = F.linear(x, self.weight)           # 冻结部分
        lora = F.linear(x, self.lora_B @ self.lora_A)  # 可训练 delta
        return base + self.scaling * lora
参数量对比：原始 W 有 out×in 个参数；LoRA 只训练 r×in + out×r = r×(in+out) 个， 当 r=8, in=out=4096 时，参数量是原来的 8×8192/(4096×4096) ≈ 0.4%。

测验

Q1 · 初始化

LoRA 为什么将矩阵 B 初始化为全零？

  • A 节省显存
  • B 加快矩阵乘法
  • C 保证初始 ΔW=0，微调从原始模型行为出发
  • D 防止梯度爆炸

Q2 · 参数量

in=1024, out=1024, r=8，LoRA 的可训练参数量是？

  • A 1024×1024 = 1,048,576
  • B 8×(1024+1024) = 16,384
  • C 8×8 = 64
  • D 1024×8 = 8,192

Q3 · α/r 缩放

LoRA 中 α=16, r=4 时的 scaling 是多少？

  • A 4.0（α/r = 16/4）
  • B 0.25（r/α = 4/16）
  • C 64（α*r = 16*4）
  • D 1.0（无缩放）

参考解法

class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, r=4, alpha=16):
        super().__init__()
        self.scaling = alpha / r
        self.weight = nn.Parameter(
            torch.randn(out_features, in_features), requires_grad=False
        )
        self.lora_A = nn.Parameter(torch.randn(r, in_features) * 0.02)
        self.lora_B = nn.Parameter(torch.zeros(out_features, r))

    def forward(self, x):
        base = F.linear(x, self.weight)
        return base + self.scaling * F.linear(x, self.lora_B @ self.lora_A)

面试要点

  • 公式：y = Wx + (α/r) * B@A@x
  • 初始化：A~N(0,0.02)，B=0（保证初始 ΔW=0）
  • 参数量：原来的 r*(in+out)/(in*out) ≈ 0.1-1%
  • 常用 r：4, 8, 16, 64；常用 α：= r 或 2r
