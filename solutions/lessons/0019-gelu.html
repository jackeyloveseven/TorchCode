GELU 激活函数

Transformer 的默认激活：平滑版 ReLU，用高斯 CDF 加权。

学习目标

  • 理解 GELU 公式：x * Φ(x)
  • 掌握精确版和 tanh 近似版的区别
  • 理解为什么 GELU 比 ReLU 更适合 Transformer

核心概念

GELU 精确定义

GELU(x) = x * Φ(x)
        = x * P(X ≤ x)   # X ~ N(0,1)
        = 0.5 * x * (1 + erf(x / sqrt(2)))

tanh 近似版（GPT-2 用的）

# Hendrycks 2016 论文的近似，更快
GELU_approx(x) = 0.5 * x * (1 + tanh(sqrt(2/π) * (x + 0.044715 * x³)))

与 ReLU 的区别

特征ReLUGELU
负值输出严格 0小负值（-0.17 左右）
0 处梯度不连续连续可微
死亡神经元可能不会（始终有梯度）

PyTorch 实现

import math

def gelu(x):
    # 精确版
    return 0.5 * x * (1.0 + torch.erf(x / math.sqrt(2)))

def gelu_approx(x):
    # GPT-2 近似版
    return 0.5 * x * (1 + torch.tanh(
        math.sqrt(2 / math.pi) * (x + 0.044715 * x.pow(3))
    ))
F.gelu 默认值：F.gelu(x) 使用精确版； F.gelu(x, approximate='tanh') 使用 tanh 近似（GPT-2 风格）。

测验

Q1 · GELU 公式

GELU(x) 等于？

  • A max(0, x)（ReLU）
  • B x * P(X≤x)，X~N(0,1)（高斯 CDF 加权）
  • C x * sigmoid(x)（SiLU）
  • D tanh(x)

  • A torch.tanh
  • B torch.sigmoid
  • C torch.erf
  • D torch.exp

Q3 · GELU vs ReLU

GELU 相比 ReLU 的主要优势是？

  • A 负值区域有小梯度，避免死亡神经元
  • B 计算速度更快
  • C 输出范围严格限定在 [-1, 1]
  • D 内存占用更小

参考解法

def gelu(x):
    return 0.5 * x * (1.0 + torch.erf(x / math.sqrt(2.0)))

# GPT-2 tanh 近似版：
def gelu_approx(x):
    return 0.5 * x * (1 + torch.tanh(
        math.sqrt(2 / math.pi) * (x + 0.044715 * x.pow(3))
    ))

面试要点

  • 精确版：0.5 * x * (1 + erf(x/√2))
  • 近似版：tanh 近似，GPT-2 使用
  • 与 ReLU 区别：负值有梯度，光滑连续
  • 用于：BERT、GPT-2（GELU）；LLaMA（SiLU/SwiGLU）
