Flash Attention

IO 感知的注意力：分块计算 + online softmax，消灭 O(S²) 显存瓶颈。

学习目标

  • 理解标准注意力的 HBM IO 瓶颈
  • 掌握 online softmax（增量 max/sum 更新）
  • 能写出分块 Flash Attention 的 Python 实现

核心概念

标准注意力的瓶颈

# 标准注意力：
S = Q @ K.T             # (S, S) → 写入 HBM
A = softmax(S)          # 从 HBM 读 S，写 A
O = A @ V               # 从 HBM 读 A，写 O
# HBM 读写量：O(S²) → 对 GPU 来说 IO 是真正瓶颈

Online Softmax（流式最大值）

# 普通 softmax 需要看完所有元素才知道 max 和 sum
# Online softmax：逐块更新 max 和 sum
# 新块到来时，用新 max 修正旧的分子/分母：
m_new = max(m_old, max(block))
sum_new = sum_old * exp(m_old - m_new) + sum(exp(block - m_new))
# 关键：exp(m_old - m_new) 是修正因子

PyTorch 实现（教学版）

def flash_attention_ref(Q, K, V, block_size=64):
    B, S, d_k = Q.shape
    scale = math.sqrt(d_k)
    O = torch.zeros_like(Q)

    for b in range(B):
        q = Q[b]  # (S, dk)
        k = K[b]
        v = V[b]
        # 对每个 Q 块
        for i in range(0, S, block_size):
            q_i = q[i:i+block_size]     # (Br, dk)
            m_i = torch.full((len(q_i),), float('-inf'))
            l_i = torch.zeros(len(q_i))
            o_i = torch.zeros_like(q_i)

            # 扫描 K/V 块（在 SRAM 中累积）
            for j in range(0, S, block_size):
                k_j = k[j:j+block_size]
                v_j = v[j:j+block_size]
                s_ij = (q_i @ k_j.T) / scale   # (Br, Bc)

                m_ij = s_ij.max(dim=-1).values
                m_new = torch.maximum(m_i, m_ij)
                exp_s = torch.exp(s_ij - m_new.unsqueeze(1))  # stable
                l_new = l_i * torch.exp(m_i - m_new) + exp_s.sum(dim=-1)
                o_i   = o_i * (l_i * torch.exp(m_i - m_new)).unsqueeze(1) / l_new.unsqueeze(1) + \
                        (exp_s @ v_j) / l_new.unsqueeze(1)
                m_i, l_i = m_new, l_new
            O[b, i:i+block_size] = o_i
    return O
实践中：直接用 F.scaled_dot_product_attention（PyTorch 2.0+） 或 flash_attn 库，内部已高度优化的 CUDA kernel。 面试只需理解思路，不需手写 CUDA。

面试要点

  • 问题：标准注意力 S×S 矩阵写 HBM，IO 是瓶颈
  • 方案：分块计算，中间结果留 SRAM，用 online softmax 累积
  • 显存：O(S²) → O(S)（不存注意力矩阵）
  • 实践：PyTorch 2.0 的 F.scaled_dot_product_attention 已内置
