第 38 课Hard

GRPO 损失

组内归一化优势：同一问题多个回答组成 group，优势 = 相对于组均值的奖励。

学习目标

  • 理解 GRPO 如何用 group 内归一化替代 value function
  • 掌握优势（advantage）计算：(r - r_mean) / r_std
  • 能写出 GRPO 的策略梯度损失

核心概念

GRPO vs PPO

# PPO 需要 critic（价值函数）估计 baseline
# GRPO：对同一问题采样 G 个回答，用组内统计作为 baseline

# 对每个问题 x，采样 G 个回答：{y₁, ..., y_G}
# 每个回答有奖励 r(y_i)
# advantage = (r(y_i) - mean(r)) / std(r)  ← 组内归一化

GRPO 损失

# 策略梯度（PPO clip 风格）
r_t = exp(logp_policy - logp_ref)   # importance sampling ratio
loss = -mean(min(r_t * A, clip(r_t, 1-ε, 1+ε) * A))

PyTorch 实现

def grpo_loss(policy_logps, ref_logps, rewards,
              group_size, beta=0.01, clip_eps=0.2):
    # policy_logps, ref_logps: (B*G,)  B 个问题各 G 个回答
    # rewards: (B*G,)

    # 计算组内归一化优势
    rewards = rewards.view(-1, group_size)        # (B, G)
    mean = rewards.mean(dim=-1, keepdim=True)
    std  = rewards.std(dim=-1, keepdim=True) + 1e-8
    advantages = ((rewards - mean) / std).view(-1)  # (B*G,)

    # importance sampling ratio
    log_ratios = policy_logps - ref_logps.detach()
    ratios = log_ratios.exp()

    # PPO-clip 目标
    surr1 = ratios * advantages
    surr2 = ratios.clamp(1 - clip_eps, 1 + clip_eps) * advantages
    policy_loss = -torch.min(surr1, surr2).mean()

    # KL 惩罚（防止偏离参考模型太远）
    kl_penalty = (log_ratios).mean()
    return policy_loss + beta * kl_penalty

参考解法

def grpo_loss(policy_logps, ref_logps, rewards, group_size, beta=0.01, clip_eps=0.2):
    rewards = rewards.view(-1, group_size)
    adv = ((rewards - rewards.mean(-1, keepdim=True)) /
           (rewards.std(-1, keepdim=True) + 1e-8)).view(-1)
    log_ratios = policy_logps - ref_logps.detach()
    ratios = log_ratios.exp()
    surr = torch.min(ratios * adv,
                     ratios.clamp(1-clip_eps, 1+clip_eps) * adv)
    return -surr.mean() + beta * log_ratios.mean()

面试要点

  • 组归一化：(r - mean_g) / std_g，替代 critic
  • ratio：exp(logp_policy - logp_ref)
  • PPO-clip：min(r*A, clip(r,1-ε,1+ε)*A)
  • 代表应用：DeepSeek-R1 等推理模型训练
