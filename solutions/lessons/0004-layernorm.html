实现 LayerNorm

Transformer 的标配归一化，关键在 unbiased=False 和 keepdim=True。

学习目标

  • 理解 LayerNorm 在最后一维归一化的原因
  • 掌握 unbiased=False（有偏方差）的用法
  • 区分 LayerNorm 与 BatchNorm 的归一化维度

核心概念

LayerNorm(x) = γ · (x − μ) / √(σ² + ε) + β

其中 μ 和 σ² 在最后一维（特征维度）上计算，对每个样本独立归一化。

与 BatchNorm 的关键区别

LayerNormBatchNorm
归一化维度特征维（dim=-1）批次维（dim=0）
依赖批大小否（batch=1 也能用）是（batch太小不稳）
用于Transformer、LLMCNN、视觉模型

Transformer 用 LayerNorm 是因为序列长度可变、batch 中不同序列应该独立归一化。

PyTorch 实现

def my_layer_norm(x, gamma, beta, eps=1e-5):
    mean = x.mean(dim=-1, keepdim=True)                    # μ
    var  = x.var(dim=-1, keepdim=True, unbiased=False)     # σ²（有偏）
    x_norm = (x - mean) / torch.sqrt(var + eps)
    return gamma * x_norm + beta

为什么 unbiased=False？

PyTorch 的 .var() 默认是无偏估计（除以 n-1，Bessel 修正）。 但归一化时我们要的是当前样本的方差，而不是对总体方差的无偏估计， 所以用 unbiased=False（除以 n）——这也是官方 nn.LayerNorm 的做法。

gamma 和 beta 的作用

归一化后数据变成均值 0、方差 1，可能破坏网络的表达能力。 γ（缩放）和 β（偏移）是可学习参数，让模型恢复所需的任意分布。 初始化：γ=1, β=0（即初始为恒等变换）。

面试要点

  • 维度：在 dim=-1（特征维）归一化，每个 token 独立
  • 方差：unbiased=False（有偏，除以 n）
  • keepdim：mean/var 计算后必须 keepdim=True 才能广播
  • 延伸：RMSNorm = 去掉减均值步骤，LLaMA/Gemma 采用
