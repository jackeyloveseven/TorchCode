实现线性层

从零搭一个 nn.Linear，理解权重矩阵为什么要转置。

学习目标

  • 理解 y = xWT + b 中矩阵形状的设计逻辑
  • 掌握 Kaiming 初始化（1/√fan_in）
  • 理解 requires_grad_(True) 与参数更新的关系

核心概念

线性层（全连接层）将输入 x: (B, in) 映射到输出 y: (B, out)：

y = x @ WT + b

为什么 weight 形状是 (out, in) 而不是 (in, out)？

PyTorch 约定（与 nn.Linear 对齐）：weight 以 每个输出神经元的权重向量 为行存储。 这样 x @ W.T 就是对每个输出神经元做内积。做转置的开销极小（stride trick，无内存复制）。

初始化：为什么乘以 1/√fan_in？

若输入 x 服从标准正态，权重随机初始化标准差为 1，则输出方差 ≈ fan_in，随层数累积会爆炸。 乘以 1/√fan_in 使每层输出方差约为 1，保持信号稳定传播。

PyTorch 实现

import math, torch

class SimpleLinear:
    def __init__(self, in_features, out_features):
        # weight: (out, in)，转置用于前向传播
        self.weight = torch.randn(out_features, in_features) * (1 / math.sqrt(in_features))
        self.weight.requires_grad_(True)
        self.bias = torch.zeros(out_features, requires_grad=True)

    def forward(self, x):           # x: (B, in)
        return x @ self.weight.T + self.bias  # (B, out)
关键点：requires_grad_(True)（in-place 版）让 PyTorch 把这个张量 加入计算图，之后可以用 .grad 读取梯度并更新。

    def __init__(self, in_features, out_features):

面试要点

  • 公式：y = xWT + b，weight shape (out, in)
  • 初始化：randn * 1/√fan_in（Xavier uniform 的近似）
  • 梯度：requires_grad_(True) 让张量参与计算图
  • 延伸：Kaiming 初始化（ReLU 后）用 std = √(2/fan_in)
